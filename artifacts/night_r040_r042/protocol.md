# R040–R042: вопросы и критерии ретроспективной проверки

База de0ed65. Ранее опубликованные результаты R7 известны; это не слепой набор. Ни нового захвата, ни обращения к устройствам. Порядок/границы из исходного R7; три стартовых R и первый не прошедший QC P14 сохраняют исходный статус.

1. Где в широком ROI следа R7 (x112:540, y1080:1270, полузакрытые координаты) цифровой цвет упирается в пределы? Для каждой из 14 принятых троек считать по исходным RGB8 долю отсчётов с каждым каналом в нуле, с любым/всеми нулями, с любым 255 и с полностью насыщенным цифровым цветом (min=0, max>0). Это наблюдения после ISP, не порог чувствительности к свету. Отдельно: доля координат с одинаковой RGB-тройкой во всех трёх снимках; не регистрировать изображения по результату. При буквальном понимании нижней границы ROI показать долю её последней строки, занятую исходной жёлтой маской R+G−2B>36, для широкого и основного узкого окна y1150:1240. Касание границы окна не доказывает отсечение прибором.
2. Выделяется ли изменение соседней уставки относительно повтора, если единица — полная фаза? Независимый архивный gate R7 проверяет все заранее заявленные D против исходных PNG, QC и DBV. Дополнительная, не заменяющая исходную, проверка: взять покомпонентную медиану трёх отсортированных распределений занятости по колонкам в основном окне; расстояние между фазами — средняя абсолютная разность, делённая на 90 строк. Сравнить диапазоны двух смежных sham, остальных пар равного DBV и последовательных переходов вверх/вниз и на обоих флангах. Строгое разделение только если минимум пересечений больше максимума контролей; общие фазы/фиксированный порядок не независимы. Проставить для всех 17 фаз план/снято/допущено, P14 только фактическая команда и раннее чтение; без численной метрики для неполных фаз.
3. Видны ли в архивных превью одновременно источник, чувствительная площадка и перекрывающий зазор непрозрачный предмет при неизменном взаимном положении? Для положительного вывода нужна наблюдаемая последовательность открыто/закрыто/открыто с неподвижными опорными точками обеих сторон. Визуально проверить фиксированный корпус: 33 фото раннего прибора (включая все shield, OFF), 15 фазовых фото пространственного A/B/A/B/A v2, 3+42+1 R7 (включая брак только для обзора поля зрения). Ярлык кадра, чёрный экран/сон, корреляция угла и неизменная рамка прибора отдельно этот критерий не выполняют.
