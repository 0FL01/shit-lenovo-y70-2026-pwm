# R016–R018: что отличает успех и отказ декодера R12b

Три завершённых архивных вопроса, но **одна и та же серия**, без нового захвата и без измерения PWM. [Критерии до пересчёта](protocol.md), [покадровый результат](outcome.json). База очереди b5daf1b; входы из рабочего пакета stock_blind_static_r12_20261118 (на момент аудита ещё не входил в HEAD a9cc189), точные версии шести используемых файлов в [манифесте](inputs.sha256). Программный пересчёт, не повторная слепая съёмка. Режим Nothing Expert 0,6×, camera 2, AE OFF. План R12b: 18, архив: 18, рассмотрено 18; исключено 0 по качеству. 3 равномерных изображения без бинарного ключа оставлены только в соответствующем отрицательном контроле; по нему 3/3 прохода. Итоговый gate R12b не пройден.

**R016 | DONE.** Статус свидетельства: confirmed-other-device (превью Nothing) для различимости рисунков, наблюдавшихся через Nothing в одной серии. Постоянные «все светлые» и «все тёмные» дают по 480/960. Неизменный шаблон, подобранный даже с доступом к *истинным* меткам всех кадров, не может превысить 576/960 (60%); фактический декодер получил 954/960 (99,375%). Для каждой позиции максимум фиксированного ответа равен большему из чисел плюсов и минусов этой позиции; сумма этих максимумов и есть верхняя граница. На четырёх разных кодовых состояниях до повторной C получено 766/768 против потолка 384/768: равное число инверсий исключает преимущество чаще повторенной C. Признак зависит от меняющегося изображения, а не только от неподвижного профиля в форме кода. Это не исключает артефакт, синхронно меняющийся со сценой. Следующий тест: независимая серия с неизвестными новыми масками.

**R017 | DONE.** confirmed-other-device (превью Nothing) только для пространственного архива. Внешнее кольцо: 2/420 ошибок (0,48%); оставшаяся сетка: 4/540 (0,74%). В (строка, столбец): p01_3 перепутал (2,5) и (2,7); p06_1 — (5,3) и (5,6); p06_3 — (1,1) и (1,8). Ни одна позиция не ошиблась дважды. Все три события были перестановками по две клетки одной строки, совместимыми с правилом top-4; не шесть независимых событий. Нельзя объявить центр хуже края, назвать физический дефект или удалить «плохие» окна. Следующий тест: на отдельной серии проверить возврат ошибки в тех же местах, не перенося/не переобучая ROI.

**R018 | DONE, с отрицательным результатом для точной привязки.** signal fail в p01_1, p01_3, p03_1, p03_3, p06_1, p06_3; среди них ровно три 62/64 из R017, остальные 64/64. Отдельно: p02_3, p04_1, p04_3 прошли signal, но не локальную геометрию. К каждому из этих кадров, ко всем проходам и плашкам нашлась одна пара pre/post по хешу изображения, независимо проверенному по binding и ordinal. Оба advancing результата в каждой паре показывают 156000 нс / ISO 6400, request 156250 нс. Наблюдаемое совпадение служебных значений подтверждено на камере (confirmed-other-device), оно не разделяет успех и отказ. Для **каждого из 18** точная связь Camera2 с конкретным sensor frame превью — unknown; следовательно, для этой более строгой задачи 0/18 парных sensor-frame результатов (не 18/18). Следующий различающий тест требует sensor-frame/timestamp для самого выходного изображения, а не более частого опроса latest result.

Пакет не опрашивает устройства, не изменяет состояние, не заявляет новый возврат и не проверяет физическую геометрию. Результаты не определяют шкалу времени, линейную яркость, частоту или глубину модуляции.

## Проверка

Из каталога отчёта задать R12B_ARCHIVE путём к исходному пакету stock_blind_static_r12_20261118:

    python3 audit.py "$R12B_ARCHIVE" | cmp - outcome.json
    R12B_ARCHIVE="$R12B_ARCHIVE" python3 -m unittest -v test_audit
    R12B_ARCHIVE="$R12B_ARCHIVE" python3 -O -m unittest -v test_audit

Python 3.13.5; 4/4 прошли и в обычном, и в оптимизированном режиме; отдельный byte-for-byte replay совпал. Без пакета replay test явно пропускается, а три синтетических теста проверяют верхнюю границу, кластеризацию ошибок и отказ при неполной/несогласной паре. Ни сырьё, ни адреса, ни идентификаторы устройств не нужны.
