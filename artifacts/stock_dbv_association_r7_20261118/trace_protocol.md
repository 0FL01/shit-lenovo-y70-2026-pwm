# Round 7: проспективный анализ фотографического следа

Зафиксировано до чтения новых растров. Это ассоциация заданного кода и формы фотографии экрана прибора, **не** физическая метрология, не пиксельное совмещение, не частота/глубина ШИМ.

1. Сначала сохранить ordinal-only CSV оригинальным `../stock_dbv_2632_20261118/analysis_ordinals.py`: все P00…P16, по три кадра; до завершения допусков не принимать завершённую серию. Пропуски/ошибки не заменять. Скрипт не читает код яркости или журнал управления. Индексы известны, поэтому это разделённые шаги анализа, а не настоящее ослепление исполнителя, который знает заранее порядок.
2. Основной признак: x=[112,540), y=[1150,1240), (R+G)/2−B>18; p(x) = доля отмеченных строк, D = среднее абсолютное различие отсортированных p(x). Для двух троек медиана девяти D, внутри тройки — трёх. Вторичный L — различие кривых средних |p(x)−p(x+k)| при циклических k=1…85. Никакой амплитуды, герц или детекции периода через D.
3. После сохранения CSV раскрыть фактические команды/проверенные коды и сравнить с заранее объявленным порядком 2632,2632,2633,2632,2631,2632,2633,2634,2633,2632,2633,2633,2634,2633,2632,2631,2632. Основной описательный критерий: минимум Dmed всех шести соседних переходов 2632↔2633 (оба направления обязательны) строго выше максимума 63 контрольных Dmed: все внутриблочные и одинаковые коды, плюс соседние переходы 2631↔2632 и 2633↔2634. Контрольные группы не выбирать после просмотра. Вывести отдельно вверх/вниз, соседей, sham-повторы и дальние одинаковые коды.
4. Все семь прежних вариантов обязательны: основной threshold18, threshold12/24, x±3, y±3 по одному. Сообщить каждый запас min(target)−max(control); не выбирать лучший. Если основной критерий не выполнен — нет разделения по заданному правилу. Если чувствительность меняет вывод — неустойчивое разделение. Даже положительный и устойчивый запас означает только описательную ассоциацию растра; без статистической независимости, p-value, causal/PWM claim. Фиксированный порядок может спутать время и уровень.
5. Временные окна: публиковать host PNG start/end, интервалы и задержку каждого первого снимка после команды, внутритроечные интервалы, полную длительность. Не предполагать стационарность до завершения задержки или непрерывную телеметрию между readback. Метаданные Camera2 по краям не идентифицируют конкретный sensor frame внутри PNG. Сравнения по времени и вариограммы — описательные, не аппаратная спектральная оценка.
6. Исторический sham при одном 2632, 51 кадр: within Dmed max0.020742; adjacent 0.010021–0.014875; all different blocks0.009216–0.020171. Для фиктивных меток первичный запас−0.010332, все варианты отрицательны. Это не порог, мощность или MDE: реальные команды и новые интервалы не имитировались. Одновременные новые controls первичны. Не объединять изображения прежних неудачных опытов с этим.
