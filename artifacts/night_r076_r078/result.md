# R076–R078: архив различает рисунки при 3600/3601, но не даёт независимого повтора

**Решение: HOLD для всех трёх штатных опытов (S).** Источники: Git `93cbb9f`, XT2611-1, GLOBAL W3WWS36.65-64-4-1, BOE cmd_v4. Аудит прочёл только три опубликованные таблицы фазовых расстояний, не сырые кадры. Это переанализ, а не проспективный результат. По каждому из R076/R077/R078: **0 назначенных к съёмке слотов / 0 снято / 0 принято**, отказ до старта, исключённых новых кадров нет. Ни один телефон не опрашивался и не менялся; нового возврата не требовалось, текущее состояние не проверялось.

**Вопрос и критерий.** Отделяются ли *в архиве* оба соседних перехода от разброса снимков одной фазы, повторов состояния и доступного соседнего контроля? Для каждого из семи старых вариантов ROI/порога отдельно: минимальный Dmin двух направлений строго больше максимального Dmax по всем указанным контролям. D — безразмерное различие изображений экрана осциллографа в режиме AC. Направление времени не меняем, новые пороги из результата не выбираем. «Разделилось» описывает этот набор фото, не физический механизм, не решение о запуске. Семь вариантов и пары одних кадров не независимы.

В первых двух архивах по 9 снимков (три фазы), в третьем 21 (семь фаз); все 39 архивных кадров представлены в агрегатах, не пересняты и здесь не переквалифицированы. Для первых двух контроль — все внутрифазные пары и первый OFF против последнего OFF. Для границы — все внутрифазные пары, 3601↔3602, разнесённые повторы 3600 и 3601 и начальный против возвращённого уровня. Максимум в таблице относится именно к перечисленным контролям, не ко всем внеграничным парам. Три последовательных сеанса, по одному на строку; значения между ними не калиброваны.

- **R076.** Старый рисунок при 3600 стоит проверять; при 3601 различия сопоставимы с разбросом. Ни один сеанс не начинается с ON и не является зеркальным R075. Без квалификации текущего сравнения, результата R075 и независимо подтверждённого исходного режима не начинать ON/OFF/ON. Нужно раздельно видеть provider, panelDC, активный SF-режим, фиксированный DBV/сцену и возврат, а не только сохранённый ключ.
- **R077.** Архивный порядок: 6879 → 3600 → 3601 → 3602 → 3601 → 3600 → 6879. Внутригрупповой максимум D основного варианта 0,034792, медианы верхнего соседнего контроля 0,013681 и 0,014444. Нижнего одношагового контроля 3599↔3600 и отдельной sham-команды в этом порядке нет; внутрифазное повторение фото — не sham-команда. Нет допуска той же сцены/метода непосредственно перед новым сравнением. Различающий тест после допуска: удержать защиту и активный режим, сравнить стык с sham и шагами с обеих сторон. Отсутствие подтверждённой штатной уставки/возврата означает HOLD, не разрешение писать напрямую.
- **R078.** Обратный участок тех же семи фаз подтверждает возврат рисунка внутри сеанса, не устраняет связь с временем/порядком. Для независимого зеркального сеанса сперва нужен прошедший R077. Далее отдельно зарегистрировать исходную яркость и режим *новой* сессии, после сравнения проверить фактическое возвращение именно к ним. Исторические 6879 нельзя назначать как универсальную величину возврата.

**Граница вывода:** `confirmed-on-target` — прежние программные readback в источниках (в архиве границы panelDC/provider 0 и SF 120 Гц в проверенных точках); `confirmed-other-device` — разделение растров фотографии прибора; `unknown` — вклад света OLED, основная частота, огибающая, глубина, направление изменения и комфорт. [Аудит геометрии и sham](../night_r043_r045/result.md): контроль из другой сессии не заменяет matched-контроль. Без независимого подтверждения оптического происхождения сигнала не объявлять изменение физического ШИМ; для качественного сравнения не требуется присваивать период.
