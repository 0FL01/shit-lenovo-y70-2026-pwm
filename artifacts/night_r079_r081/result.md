# R079–R081: что ещё различают штатные сравнения

**Все три физических опыта остаются HOLD.** Офлайн пересчитаны опубликованные агрегаты для XT2611-1 / GLOBAL W3WWS36.65-64-4-1, исходная ревизия `4e47a28`. Для каждого нового опыта назначено / снято / принято **0 / 0 / 0**; не было включения функции, команд яркости, обращения к приборам или нового возврата. Архивная и нынешняя сессии не объединены. Физические герцы, глубина модуляции и комфорт остаются неизвестны.

**R079 · 2632↔2633.** В [частичной 17-фазной серии](../stock_dbv_r7_ordinal_20261118/result.md) доступны 14 полных фаз (42 кадра); первый кадр P14 отвергнут, не заменён. Для сопоставимости времени здесь берём *только непосредственно соседние команды*, не все пары: из 13 переходов пять пересекают интересующий стык, два повторяют тот же код, два переходят 2631↔2632 и четыре 2633↔2634. По исходному Dmed медиан девяти растровых расстояний между тройками, диапазоны соответственно **0,010151–0,012980; 0,011085–0,014901; 0,011942–0,012279; 0,012591–0,018302**. Только 8 из 40 попарных сопоставлений дают «переход больше контроля»; при семи прежних вариантах порога/ROI 7–16 из 40, ни разу не 40. Это описательный счёт пересекающихся пар, не вероятность, не 40 независимых испытаний и не оценка отсутствия эффекта. Даже без несмежных контрольных пар этот метод не допускает новый опыт. Для допуска нужен независимо квалифицированный метод на той же сцене и кодах с двухсторонним одношаговым контролем и повторной командой без изменения кода.

**R080 · Extra Dim.** В [первой серии](../STOCK_EXTRA_DIM_20261118.md) выдержка не менялась, но ISO составил 9827 / 12681 / 9117 (OFF / единственный ON / возврат). Такой контраст непригоден. В [следующей серии](../stock_extra_dim_locked_20261118/result.md) входная центральная сцена совпала, readback DBV 828; матрица Android менялась 1 → 0,522 → 1. Девять архивных JPEG при 59,99832 мс, ISO 5586; EXIF согласуется с полноценными PREVIEW-результатами до и после спуска, один неполный post-read был повторён. Это штатная блокировка AE/AF, **не** девять синхронизированных STILL results и не полностью ручная камера (AWB не заблокирован). По [таблице кадров](../extra_dim_round2_raster_audit_20261118/derived/frames.csv) доля R>192 в нижней полосе фото прибора: OFF 59,88–70,00%, ON 9,00–9,97%, возврат 53,35–62,88%. Между *каждым* OFF/возвратом и *любым* ON не менее 43,38 процентного пункта. Это один последовательный проход, без независимого оптического контроля. Для нового опыта подтвердить неизменность сцены/DBV, ручной экспозиции по фактическому Camera2 в каждой фазе и возврат; архивную блокировку не выдавать за выполненный новый протокол.

**R081 · равнояркий серый.** В [попытке белый+Extra Dim против серого](../stock_extra_dim_gray_20261118/result.md) дважды не прошёл AF (`NOT_FOCUSED_LOCKED` при AE LOCKED), до первого тестового снимка и смены сцены. Не было пары с подтверждённым одинаковым видимым уровнем. Для диагонали матрицы 0,522 код 133 даёт 133/255=0,521569, но после декодирования sRGB линейное значение 0,234551; у 191 это 0,749020 и 0,520996. Это две гипотезы места применения матрицы, а не две фотометрические калибровки. Будущий опыт требует сначала независимо сопоставить средние оптические уровни с тёмной поправкой при фиксированном DBV, измерить повторяемость уровня и заранее задать допуск, а затем проверить контраст без автоусиления. При неподтверждённом соответствии яркости не приписывать различие Extra Dim отдельно от уровня.

`confirmed-on-target` — прежние readback и программная матрица; `confirmed-other-device` — только различия растров и метаданные камеры; `unknown` — изменение оптического ШИМ и пригодность режима пользователю. Ни одно здесь не доказывает ≥2 кГц.

Код читает ранее опубликованные CSV/JSON; не повторяет извлечение из JPEG, опрос Camera2 или измерение уровня. [Числа по всем вариантам](outcome.json).
