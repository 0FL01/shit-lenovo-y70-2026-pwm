## Числа и ограничения

Поиск fine 0,015–0,025 выбран по baseline до сравнений. Найденный q
зафиксирован. Основной расчёт: spatial quadratic detrend + Hann,
без вычитания временного среднего.

| ROI | sham / baseline fixed fine | return / baseline fixed fine |
|---|---:|---:|
| left | 1,0052820111 | 1,0153407949 |
| main | 1,0094375428 | 1,0092808148 |
| right | 1,0055645404 | 1,0079102110 |

Main mean Y: 31,79978009 → 31,80928704 → 31,90004630.
Main normalized fine: 0,2801356615 → 0,2827794538 → 0,2827355487.
Все ROI: Y=14–45, без Y≥235. Fine вывод сохраняется для detrend
None/1/2/3; fixed 2q/3q близки к baseline.

RMS/(mean Y−16) — метрика кодов камеры, не физическая глубина модуляции.
Полный диапазон 0–0,5 цикла на строку, total/coherent/incoherent,
detrend sensitivity и блоки сохранены в [JSON](optical_analysis.json)
и [NPZ](optical_profiles.npz).

Почему результат ограничен:

- Full-spectrum relative L2 amplitude difference sham: 3,85–3,93%;
  return: 10,76–11,37%. Это расстояние кодовых амплитудных кривых,
  не процент оптической мощности.
- Наибольшая return-разница около q=0,00488–0,00513, в широкой структуре.
- Main q/6: 0,07211115 → 0,07379816 → 0,07671303.
  Return/baseline left/main/right: 1,04508 / 1,06382 / 1,01371.
- Main return q/6 при None/1/2/3 detrend:
  0,76285 / 0,84332 / 1,06382 / 1,07410. Направление оценки меняется.
- Main 20-кадровые q/6 блоки: baseline 0,06835–0,07771;
  sham 0,06957–0,07883; return 0,07370–0,08169.
- Main tail maximum 0,1–0,5:
  0,05557118 → 0,05452730 → 0,05233142.

В ROI менее двух периодов условного q/6; q/6 не объявляется физическим
fundamental. Соседние ROI/короткие блоки не являются независимыми опытами.
Экспозиция, ISP, нелинейность и aliasing ограничивают вывод. Полный waveform,
низкочастотная огибающая, ≥2000 Гц и комфорт не установлены.

Независимая numerical/native-Y/timing проверка — PASS. Свежий ffprobe
подтвердил все 2339 PTS; отдельный расчёт воспроизвёл primary/stronger окна
и условные запасы. Full-native-Y decode кадров 536/1440/2045 с crop после

monomial Fourier для None/1/2/3 совпал с нормированными метриками с ошибкой
≤3,40×10⁻¹⁶, полный FFT power — ≤1,78×10⁻¹⁴. Return L2 различия
воспроизведены отдельно. Saved-hardware/lifecycle/cleanup также прошли
независимую проверку.

Второй полный decode воспроизвёл JSON побайтно и все 32 NPZ-массива точно.

блоки и более строгие временные запасы; middle_c1_status остаётся
not_measured. [validate_optical.py](validate_optical.py) повторяет проверку.

Исходный run/video, старые результаты и shared sources не изменены;
