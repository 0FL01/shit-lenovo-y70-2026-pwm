# Раунд 8: к чему чувствительна фотография и где искать второй канал

**Кратко.** Порядок столбцов можно проверять без новых кадров: на 51 реальном контрольном растре продемонстрирован класс изменений, полностью невидимый исходной мере D, но заметный по спектру растра. Отдельно в двух архивных сериях над экраном осциллографа есть область, яркость которой менялась вместе с тестовой картинкой. Это кандидат для опыта на отражённом свете, а не доказательство, что камера видит свет именно OLED. **Частота и глубина оптического PWM остаются неизвестны.**

## 1. Численный положительный контроль пространственного порядка

Для исходного кадра берём p(x) — долю пикселей маски (R+G−2B>36) в каждой колонке x=112…539, y=1150…1239. Сравнение сортированных значений D не различает перестановки в принципе. Для каждого из 51 sham-профилей построили p′(x)=p((3x) mod 428); индексы образуют биекцию. Результат: **D=0 для всех 51**, при этом половина L1-расстояния нормализованных мощностей numpy.rfft, без DC, min/median/max **0.89382/0.91399/0.93530**. Это положительный контроль математического экстрактора, а не физически возможная модель переключения панели. Не исключает, что старый вторичный L также различает перестановку.

Отдельная синтетическая инъекция: добавить к p синус амплитуды h (в долях занятости колонки), обрезать в [0,1]. Фазы jπ/4, j=0…7; h∈{.01,.02,.04,.08,.16}. В каждом из пяти **отдельных** бинов k считать A=2|mean(p exp(−2πikx/428))|. Потолок — максимум A из 51 исходного sham того же бина. В таблице h — первая **лишь из проверенной сетки**, при которой все 51×8 синтетических вариантов превысили потолок; это не предел обнаружения (в частности, не MDE по физической модуляции).

| k / пикселей на цикл | Потолок sham | h | Диапазон исходных A в принятых R7 | Число R7 выше потолка |
|---|---:|---:|---:|---:|
| 8 / 53.5000 | .03492 | .08 | .00082–.03024 | 0 |
| 16 / 26.7500 | .03124 | .08 | .00147–.02783 | 0 |
| 32 / 13.3750 | .04859 | .16 | .00130–.04333 | 0 |
| 64 / 6.6875 | .02027 | .04 | .00084–.01930 | 0 |
| 128 / 3.34375 | .02012 | .08 | .00329–.02243 | 1 |

У k64 запас при h=.04 лишь ≈.00005. Все прошедшие пробы были добавлены *после* извлечения p, не в излучение или фотографический тракт. Интегрирование, размытие, перспектива, конечное окно/утечка и алиасы могут скрывать полезный свет или создавать пики. Одиночное превышение в 42 кадрах × 5 бинах не устанавливает связь с DBV. Задний анализ пиксельных частот не квалифицирует временную базу. Для будущего независимого опыта стоит заранее фиксировать бины/контроли и допуски, в том числе демонстрировать ожидаемый отклик на независимом физическом положительном контроле.

## 2. Проверка области вне дисплея прибора

На более старых превью Nothing PHOTO фиксированная полоса y=[310,530) выше видимого экрана прибора, три окна по x: слева [60,280), в центре [370,690), справа [760,990). Для каждого окна: арифметическое среднее по RGB и всем пикселям, затем **медиана трёх кадров** каждого блока. DN — значения обработанного 8-битного изображения, не линейная фотометрия.

| Архив/окно | Последовательность медиан DN |
|---|---|
| W/B/W слева | 15.67 → 14.09 → 15.06 |
| W/B/W центр | 16.05 → 14.03 → 15.72 |
| W/B/W справа | 13.58 → 10.77 → 13.04 |
| A/B/A/B/A слева | 15.70 → 13.54 → 15.29 → 13.61 → 15.50 |
| A/B/A/B/A центр | 15.99 → 13.84 → 15.73 → 13.87 → 15.69 |
| A/B/A/B/A справа | 12.89 → 11.45 → 12.55 → 11.37 → 12.41 |

Разведочная проверка на простой общий коэффициент усиления: покадровый ln(центр/право), затем медианы троек, в A/B/A/B/A = **.2244/.1899/.2283/.1955/.2270**. При строго одинаковом мультипликативном усилении всех пикселей такое отношение было бы неизменно. Это не поправка на реальный AE: уровень чёрного, нелинейный ISP, локальная тональная коррекция, AWB и переменный спектр, шум, отражение от самого дисплея прибора и его индикаторов не исключены. В W/B/W медианы той же величины .1623/.2645/.1782; направление между этими двумя разными протоколами не обобщать.

У R7 другая геометрия. Справа от экрана прибора x=[640,1000), y=[950,1280) медианы по блокам 1.95–2.07 DN; в отдельных кадрах 29.7–35.4% пикселей имеют хотя бы один нулевой канал. Ниже прибора x=[100,540), y=[1500,1640) медианы 7.91–8.05 DN, соответствующая доля 4.0–5.4%. Нижняя область даёт больший запас в тенях, но расположена рядом с индикаторами; наличие прямого или отражённого света цели не квалифицировано. Старые и новые окна нельзя считать одной областью/одной оптикой.

**Следующий различающий опыт без перестановки стойки** (предложение, не выполнялся): с фиксированным профилем съёмки заранее закрепить границы полей и независимую отрицательную область, выполнить сбалансированные пространственные метки при одинаковой построчной APL/DBV, регистрировать экран/индикаторы самого прибора как отдельный возможный источник засветки, проверить новые отложенные маски и заранее заданные возвраты. Выделять отклик только если он воспроизводится на отдельной серии и выдерживает sham/контроль тёмного уровня; при соответствии изменению изображения прибора оставить происхождение **неопределённым**. Даже надёжное обнаружение *медленной метки* не измеряет 2 кГц. При отсутствии независимо идентифицированного оптического пути не заменять физическую развязку дополнительной математической обработкой.

## Воспроизведение

Python 3, NumPy, Pillow. Аргументы: каталоги исходных 51 sham, R7, старого W/B/W и старого пространственного прогона, именно в таком порядке:

    python3 -B replay.py PRIVATE_SHAM PRIVATE_R7 PRIVATE_WBW PRIVATE_SPATIAL > replayed.json
    cmp replayed.json results.json

[Скрипт](replay.py) ничего не снимает, не пишет на устройства, не читает сетевых адресов. [Результат](results.json) содержит только производные числа; фотографии и приватные журналы не публикуются. Для проверки воспроизводимости normal/−O сравнивать в той же среде Python/NumPy/Pillow.
