# Критерии R052–R054; база 53e7cfb

Только архив репозитория и синтетика. Новых физических съёмок не планируется. Существующие отчёты уже известны; инвентаризация ретроспективная. Пара слов подобрана при проектировании как код с проверкой коллизий, не как статистическая выборка.

* **R052:** есть ли в проверенных материалах фиксированная протяжённая матовая область отдельно от прямого OLED, стекла, прибора и UI, соседний одновременный контроль, различимый ответ A/B с возвратом сверх sham при фиксированном gain? Для физической калибровки необходима также независимая запись фактических оптических фронтов. Непроверенный фон не считать мишенью; без этих условий ветка калибровки HOLD.
* **R053:** для кандидатов из отчётов о стенде, таймингах, другом телефоне и датчике указать источник такта, что реально регистрировалось и есть ли привязанный к серии измеренный момент *излучения*. Сведения Android, номинал источника, повтор сигнала неизвестного происхождения не заменяют такую запись. Отсутствие подходящего кандидата — результат инвентаризации, а не физическая проверка.
* **R054:** конечная модель квадратного растра: идеальные полосы, три уже различимых упорядоченных уровня, один отсчёт на слот, один **полный** цикл; либо не пропущено ничего, либо удалён один отсчёт с неизвестным индексом (без метки пропуска). На входе только квадрат уровней 12×12 или 11×11. Сторона одинакова вдоль обеих осей, ориентацию не подсказывает форма. Для основного кода требуем единственное точное решение: ось x/y, знак, индекс первого сохранившегося слота, индекс потери либо null. Проверить все 12 фаз, оба знака, обе оси, без потери и с потерей в каждой из 12 позиций. Плоский фон, неоднородная поперечная структура, укороченный на два слота цикл — unresolved. Запасное слово зафиксировано отдельно: проверить отсутствие пересечения его идеальных сигнатур с основными, но не использовать для выбора модели и настроек по реальным данным. Два пропуска, неизвестный масштаб, физическое размытие, произвольный crop, произвольное квантование и затенение вне этого допуска.
