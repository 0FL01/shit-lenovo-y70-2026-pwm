# Проверка замороженного признака 17 px на 63 архивных снимках

**confirmed-other-device:** на штатной сцене ZRam при 3600/OFF выбранная в [R109](../night_r109_r112/result.md) компонента фотографии прибора действительно сильнее и возвращается. В двух других сценах перенос правила «светлая область → больше A17» не сработал: фазовые медианы выше на чёрном и на белых краях, хотя локальная повторяемость гребёнки там хуже. Это проверка пригодности признака, **не** эксперимент по перекрытию пути. Новых съёмок/команд устройствам: 0.

| Архивная серия, фазы по порядку | Число снимков | A17, медиана трёх снимков на фазу (коды красного PNG) |
|---|---:|---|
| [ZRam, 3600: OFF / ON / OFF](../scope_dc_divergence_20261118/result.md) | 9 | 28,419 / 5,545 / 28,593 |
| [ZRam, 3601: OFF / ON / OFF](../scope_dc3601_divergence_20261118/result.md) | 9 | 5,280 / 5,752 / 2,502 |

| [3600 OFF, белый центр / края / центр / края / центр](../scope_spatial_divergence_20261118/result.md) | 15 | 5,205 / 9,674 / 5,931 / 10,682 / 6,453 |

**Что считали.** Без интерполяции, настройки частоты или выбора другого окна: у исходного 1080×2392 PNG берём красный, для каждой колонки x=[105,819) медиану по y=[926,958). Для полученных 714 значений r[j] считаем A17=(2/714)·|Σ r[j] exp(−2πij/17)|. Это пик амплитуды синусоиды в кодах фото при выбранной нормировке, не мощность, контраст OLED или физические Hz. 42 целых периода исключают вклад постоянного уровня; дисперсия кадра в знаменатель не входит. На всех 63 снимках прямое вычисление совпало с FFT-коэффициентом №42 (допуск 10⁻⁹). Дополнительная идентификация исходных фото: сверены обе полные последовательности локальных максимумов прежних ACF полосы (на 6 px шире) и сетки для каждого кадра по публичным таблицам в 76f3c5bb; это отпечаток признаков, не криптографическая аттестация. Проверены порядок фаз, число кадров и архивные ранние/поздние DBV, DC, provider (**confirmed-on-target** для этих readback).

**Граница результата.** На ZRam 3600 все шесть OFF ≥26,101, все три ON ≤8,673: зазор 17,429 кодов. В другом прогоне по границе обе фазы 3600 выделяются на той же сцене и при том же OFF. Это не независимое повторение переключения DC; 63 связанных кадра из пяти архивных последовательностей не означают 63 независимых опытов. Для белого/чёрного и центра/краёв указан порядок медиан, а не полное разделение отдельных кадров.

Почему результат не противоречит старой автокорреляции: как **описательную** диагностику разбили ту же полосу на 42 последовательных блока по 17 px. Если z — комплексная проекция каждого блока с множителем 2/17, то A17=|mean(z)|=mean(|z|)·C, где C=|Σz|/Σ|z| (при ненулевом знаменателе). У белого/чёрного/белого медианы C = 0,873 / 0,447 / 0,842, медианы локального модуля = 7,20 / 26,39 / 8,70 кода. На чёрном фазы блоков менее согласованы, но локальные вариации красного больше. Это разложение **изображения**; C и локальный модуль не являются заменой A17, критерием успеха или измерением мощности света. Перемножать отдельно взятые медианы не нужно: тождество действует для каждого отдельного фото.

**Идентифицируемость.** Все пять воздействий оставляют возможными и изменение света, и изменение токов панели/синхронизации прибора. Если на входе прибора сумма оптического и электрического вклада, то те же фотографии допускают перенос зависящей от режима части из одного вклада в другой без изменения суммы. Дополнительный цифровой readback, больше фото или подтверждение модуляции второй камерой сами по себе не измеряют эти два вклада раздельно. [Поиск по 94 архивным обзорам](../night_r040_r042/result.md) не нашёл документированного перекрытия при неизменной сцене. В проверенной базе нет независимого управления прозрачностью этого зазора. Зажжённый экран с чёрным контентом или с другой геометрией белого такую проверку не заменяет. Происхождение, направление изменения оптической частоты, глубина и комфорт **unknown**. При появлении подходящей записи сохраняется прежнее условие R109: тот же светящийся экран/сцена и метрика, отдельное селективное перекрытие с sham и проверенным возвратом. На другую сцену нельзя переносить численный порог ZRam; менять метрику после наблюдения не предлагалось. Никаких действий со стендом не требуется.

**Воспроизводимость.** [Все значения по кадрам](result.json), [пересчёт](replay.py), [тесты](test_replay.py). Из каталога отчёта в Git-клоне с базой 76f3c5bb: `python3 -B -m unittest -v`; для архива через Python 3 с NumPy и Pillow:

```sh
python3 -B replay.py --dc3600 "$DC3600_RECEIPT" --dc3601 "$DC3601_RECEIPT" \
  --boundary "$BOUNDARY_RECEIPT" --color "$COLOR_RECEIPT" \
  --spatial "$SPATIAL_V2_RECEIPT" | cmp - result.json
```

Исходные receipts и PNG остаются в лаборатории; публичный JSON содержит только фазовые метки и безразмерные/цифровые признаки. Это новый пересчёт прежнего материала, не новый физический опыт.
