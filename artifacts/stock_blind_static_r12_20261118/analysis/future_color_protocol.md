# Color is a separate prospective experiment, not an R12 endpoint
Archived R11 source A contains only the two neutral SVG fills #383838 and #b8b8b8. Nevertheless, on the four short previews the signed high-minus-low median in R−B is −16.19, −18.94, −17.82 and −17.53 preview DN; R−B row-centered correlation with A −.9544, −.8948, −.9510 and −.9505. Reading opponent amplitude or separate channel bit accuracy on a grayscale mask is not evidence for chromatic discrimination. A uniform plane is necessary but misses this grayscale leakage.
A later protocol should use a separate labeled development run; do not append this endpoint to a running grayscale test. A possible source palette A/B, (160,110,90) and (80,125,178), nearly matches *digitally encoded* Y' (119.186,119.260) at one nominal setting. This does NOT establish equal physical luminance, linear-light Y, equal camera Y, or constancy under display/ISP changes. Develop a second pair at another nominal intensity in advance, avoiding preview clipping. Freeze palette, exposure/WB settings or witness, and analysis before blind acquisitions. Reference patches adjacent to the analyzed tile can witness changing white balance; do not use held-out bits to fit transforms.
Use crossed, balanced, independent luminance and chromatic binary factors: exactly two cells per (luminance, color) combination per row, fresh shuffled positions every row. Include grayscale-only phases with identical luminance factors and neutral colors, uniform sham, chroma-sign inversion at unchanged luminance, and a second independent code. Keep source profiles, camera settings, alignment, pixel-sampling and analysis frozen. Commit keys and predictions. Measure signed opponent separation within EACH luminance stratum versus its corresponding gray sham. Require chroma discrimination separately at both luminances and with inversion in the predeclared direction, not merely a pooled effect. Evaluate a Y'-only competing decoder, wrong chroma code, wrong sign, and grayscale-only leakage; if luminance alone predicts colored states, do not claim independence from luminance. Determine numeric tolerances from development captures/fixed task requirements before the new blind holds, not R12 or later evaluation. No post hoc channel choice.
For a preview-domain repeatability estimate, replicate non-identical camera frames without stimulus change; report per-cell temporal median deviation, pooled robust dispersion, 95th abs deviation, maximum, dropout/worst-row statistics, and across-block replication, alongside signed effect sizes. Ratios labeled CNR/preview discrimination only when specifically defined; neither gamma-coded screenshot values nor white-balanced channels are calibrated luminance, raw sensor SNR, chromaticity, panel modulation or timing. Never infer Hz from spatial bands or HAL skew.
