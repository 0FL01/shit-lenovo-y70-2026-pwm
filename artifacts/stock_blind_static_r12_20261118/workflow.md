# Разделение предсказания и операторских данных

1. Аналитик заранее зафиксировал алгоритм, опираясь только на R10/R11. Подтверждены SHA-256 манифеста метода `5285639f7dccff76abab209a2c5280d5c4c42a1a6c8aabde2225a3098c88b35f`, карты двух ближайших ориентиров `9dbee9c74ab13379155516aebcb855adc676b9c7ca47fe2f58db4edff30d4aa8` и исходного алгоритма проверки этих ориентиров `9fec33994c4f46e773f58f6099c99365f6b79179e85ff3dfc575bc866adc9c28`.
2. Подготовительный запуск R12a остановлен до 0.6×. Его не смешивают с R12b. Свежая случайная разметка R12b была закоммичена SHA-256 до открытия камеры/показа страницы: `6684bf87f9ef6de8c6d33a9b6118aabb988d6926facf4accd7616f2ea176d747`. Коммитмент — хеш закрытых байтов с солью, а не git commit.
3. Операторский процесс читает HTML отдельно от анализа. В каталог для предсказания копирует только скриншоты Nothing с порядковыми именами; там нет HTML, key, кадров источника, описаний или метаданных, раскрывающих разметку. У оператора в архиве отдельно лежат полные исходные данные, включая исходный и конечный скриншоты каждой страницы, два readback Camera2 по краям отдельного скриншота и журналы восстановления.
4. Шесть неподвижных состояний: независимые C,D, их инверсии, ровное поле 120, возврат C. Первые пять переставлены случайно до опытов, последняя — C без соседнего повторения C. По три предписанных скриншота каждого, без поиска удачных кадров или замены. Ровное поле имеет тот же **номинальный цифровой** средний уровень, но не претендует на физическое равенство освещённости.
5. Сопоставление результатов с исходными кодами допустимо только после сохранения хеша файла предсказаний. Это слепое предъявление для отдельного аналитика/процесса в общей лаборатории, а не криптографическая изоляция между разными пользователями ОС. Результат ограничен распознаванием пространственного рисунка, не измерением частоты или шкалы времени.
