# Причинная проверка остальных кандидатов DC/тайминга (`23:85`, `23:80`, `53:95`, `53:A2`, `23:A9=0x06`, обёрнутая `4F:81`)

## Условия опыта

Все фазы выполнены на стенде (`Lenovo XT2611-1/PVT`, `W3WWS36.65-64-4-1`, `ILI97701A cmd_v4`) при фиксированной яркости **`DBV 3600`**, **`panelDC=0`**, **120 Гц** на белом патче `#FFFFFF` (`HTMLViewer`) под контролем нативных 10-битных DNG `0,6×` (`Camera ID: 2`, `EXPERT 0.6×`, `RAW ON`, `ISO 6400`, выдержка **`625 мкс`**, по 2–3 кадра на фазу). Обработка идентична [`analyze_2d_modulation.py`](../pwm_06x_dng_bench_20261119/analyze_2d_modulation.py) (истинно зелёные CFA-сайты `(G1+G2)/2`, белый ROI из 288 блоков `5×5`, референс `IMG_20260502_083009182.DNG`, `sinc_fit: null`).

Каждая запись проверялась в изолированном `unshare -m` пространстве с временным `esd_sw_sim_success`, немедленным возвратом на страницу `0x00`, обратным чтением записанных байтов и проверкой `esd_check_mode = reg_read` после каждой фазы. Полные метрики и SHA-256 всех 39 DNG (38 новых + референс) находятся в [`summary_round2_20261119.json`](summary_round2_20261119.json).

## Выводы

1. **Отрицательные причинные проверки на `625 мкс`:** при успешном обратном чтении ни одно из шести изолированных воздействий — `23:85` (`0x15→0x14`, кандидат из `p85_single_bit_plan`), `23:80` (`0x50→0x90`), `53:95` (`00 a0→44 50`), `53:A2` (30-байтный LUT `DC ON`), младшие биты `23:A9` (`0x0e→0x06`, где `0x0611=1553 < DBV 3600`) и `4F:81 = 0x03` даже внутри полной штатной обёртки фиксации (`08:98 02 / 4F:88 78 / 08:98 a6 / 00:00 00 / 4F:8B 78`) — не подавило и заметно не сдвинуло измеренную моду `[±2, ∓1]` при `DBV 3600` и выдержке `625 мкс`: во всех кандидатских фазах записи без выраженного провала `F(-2,+1)` составила **`0,0772–0,1146`** (вместе с фазами возврата `0,0772–0,1168`, против модельного ориентира `0,1547 · |sinc(720·625e-6)| ≈ 0,1081`), средний сигнал зелёного ROI — `8,23–8,81 DN`. Одна выдержка `625 мкс` без `sinc`-свипа не разделяет частоту и глубину независимо и не исключает делитель при кратных алиасах или другом режиме, но показывает отсутствие подавления/сдвига наблюдаемой моды от каждого из шести полей порознь.
2. **Уточнение модели `DC OFF ↔ DC ON`:**
   - С учётом первого раунда (`artifacts/ddic_4f81_23a9_06x_dng_20261119`, один цикл запись/возврат, во 2-м раунде не повторялся) из проверенных отличий таблицы `qcom,mdss-dsi-dc-off-command ↔ dc-on-command` **единственным** изолированным изменением, для которого наблюдалось обратимое подавление компоненты `F(-2,+1)` при `DBV 3600`, остаётся **старший бит `23:A9[7]` (`0x0e ↔ 0x8e`)**.
   - Запись `23:A9 ← 0x06` (`0x0e11 → 0x0611`, `1553 < 3600`) при неизменном `DBV 3600` (без последующего обновления яркости/DBV) оставила моду `[±2, ∓1]` активной. Это противоречит модели компаратора, немедленно срабатывающего по записи в `[23:A9, 23:AA]`, хотя не проверяет пересчёт при последующей записи DBV и не локализует, на каком уровне стека происходит сравнение порога `3601`.

## Восстановление стенда и следующий шаг

Финальное чтение подтвердило возврат всех затронутых регистров (`23:85=0x15`, `23:80=0x50`, `23:A9=0x0e`, `4F:81=0x10`, `53:95=0x00 0xa0`, `53:A2=0x10 0x10 0x10 0x10 0x48 0x10 0x10 0x10 0x4b 0x4b...`, `esd_check_mode=reg_read`).
