# R085–R087: одна полоса не идентифицирует источник

**DONE, только синтетика A.** Постановка на базе `4e47a28`: [протокол и критерии](protocol.md), [модели](audit.py), [результаты](results.json), [регрессии](test_audit.py). R085 3/3 пары, R086 5/5 окон, R087 3/3 набора фронтов; все сгенерированы и приняты для анализа, исключено 0. Отказ назвать период/частоту является результатом, а не исключением образца. Новых физических наблюдений 0, действий на обоих устройствах 0, возврат неприменим. Для реальной панели соответствие моделей, частота и глубина — `unknown`.

**R085.** На плоской неизменной сцене две разные модели дают одну и ту же построчную яркость: для равномерного источника наклон фазы равен 720/300000 цикла/строку; для бегущей синусоидальной развёртки он равен 120/300000 + 1/500. Локальный наблюдатель второй модели видит 120, а не 720 Гц. Обе величины параметрические. После усреднения экспозиции разница максимум 5.6×10⁻¹⁶ на шкале 0–1: у двух источников независимые допустимые амплитуды, выбранные так, чтобы наблюдаемый контраст совпал. При известной общей задержке 1 мс исходные фазы разошлись (максимум 0.566); при отражении пространственной фазы второй модели — 0.486. Фаза/амплитуда между кадрами здесь не подгоняются. **Вывод:** это контрпример достаточности одного кадра, а не описание реальной развёртки. Различающий тест в будущем: фазово привязанная серия при известной задержке и неизменной геометрии; свободная фаза каждого кадра контролем не служит.

**R086.** В окнах 3/12/24/48 модельных циклов шаг сетки 1/T = 240/60/30/15 Гц. Относительный RMS после подгонки ошибочного кандидата 750 к чистому 720 соответственно 0.224/0.771/1.000/1.000, правильного — 0 во всех четырёх. Окна 3 и 12 не прошли заранее выбранное требование длины. Для этой пары политика требует ≥24 цикла по 720 (33⅓ мс): максимум двух нижних границ, 3 цикла и один интервал биений. Это консервативное правило планирования, не универсальный предел оценивания; синтетический тон без шума различим по остатку и раньше. Смесь равных линий на 24 циклах дала остаток 0.707 для каждой: выбираем **ни одну** из одиночных моделей. Следующий тест метода: сравнить повторные окна с контролируемыми шумом, джиттером, искажением формы и смещением частоты между узлами сетки. Порог 5% сюда не переносить без оценки шума и шкалы.

**R087.** Без пропуска период 8 тиков дал 8 пар ACF на лаге 8 против 7 на лаге 16; после центрального пропуска 6 против 5, интервальная модель в обоих случаях дала только {8}. В коротком отрезке два события разнесены на 16 тиков: ACF показывает лишь 16 (одна пара), но эквивалентны P=16 без пропуска и P=8 с одним. Результат **{8, 16}**, не частота 1/16. Без ограничения «не более одного пропуска» набор мог бы расшириться. Следующий различающий тест: увеличить непрерывное окно с тем же детектором, проверить качество фронтов и остатки интервалов на независимой записи с атрибутированными часами.

Воспроизведение из этого каталога: `python3 -B -m unittest -v` (3/3), `python3 -B audit.py` (JSON). На этом наборе ни подтверждения, ни опровержения физического ШИМ Lenovo нет.
