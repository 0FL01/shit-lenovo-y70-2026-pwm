## R083 / DONE: когда гармоника выше основной

Вопрос: достаточно ли менять одну скважность, чтобы максимальный пик перестал означать основной период? Идеальные периодические прямоугольники; считаем амплитуды линий f, 2f, 3f **до** оптики и семплирования. Не ищем любые локальные максимумы или наибольшую линию всего спектра. Пусть k равно числу импульсов за истинный период T; старт j/k, ширина w=d/k в долях T, d — суммарная доля времени «выше нуля», веса заданы в таблице. У всех трёх моделей при 0<d<1 минимальный период T: только один самый высокий импульс за T. Амплитуда n-й линии: 2w |sinc(nw) Σ aⱼ exp(−2πinj/k)|, sinc(x)=sin(πx)/(πx).

Критерий: амплитуда выше A₁ более чем на 10⁻¹². Сетка d=1%,2%,…,99%: **297/297 профилей** вычислено, 0 исключено. Диапазоны включают границы сетки; вне сетки это не оценка порогов панели.

| Повторяющийся рисунок | A₂ > A₁ | A₃ > A₁ |
|---|---|---|
| Один прямоугольник высоты 1 | ни при одном d | ни при одном d |
| Два с высотами 1; 0,65 | 1–86% | ни при одном d |
| Три с высотами 1; 0,65; 0,65 | ни при одном d | 1–88% |

Для одиночного прямоугольника A₂/A₁=|cos(πd)|, A₃/A₁=|1+2cos(2πd)|/3: изменение только d не делает эти гармоники сильнее. В многопульсном случае повторение похожих частей усиливает кратную линию, хотя разница высот сохраняет более длинный истинный период. Это **hypothesis** о возможной неоднозначности интерпретации панели, а не сведения о её форме импульса.

## R084 / DONE: две пары, разные причины сходства

Вопрос: совпадут ли **упорядоченные**, а не отсортированные полосы двух разных сигналов? 64 равноотстоящие строки, общий фиксированный масштаб 0–1 и среднее 0,5; сходство — RMS разности ≤0,015 без сдвига, масштабирования и поиска лучшей фазы. Этот проектный допуск не является шумовым порогом камеры. Частоты ниже — заданные модельные числа. c(f) = cos(2πft); экспозиция — центрированное прямоугольное интегрирование. **5/5** модельных сравнений вычислены, 0 исключено.

1. **Алиас.** A = 0,5 + 0,22c(720) + 0,06c(2160); B = 0,5 + 0,28c(2160). При 2880 строках/с и нулевой начальной фазе c(2160)=c(720) на решётке. Мгновенная выборка обоих даёт 0,78; 0,50; 0,22; 0,50 (повтор), RMS=0. При общей выдержке 100 мкс RMS=0,010344: всё ещё «похожи». При 11520 строках/с с той же выдержкой RMS=0,210941: различимы. Отдельный идеальный контроль при 2880 и общем известном сдвиге начала на ¼ строки даёт RMS=0,22. Неизвестная фаза в реальной записи не даёт права считать этот контроль выполненным.
2. **Слабая основная, без алиаса.** C = 0,5 + 0,015c(720) + 0,23c(2160); D = 0,5 + 0,23c(2160). При 11520 строках/с, идеальной выборке и целом числе периодов RMS=0,010607 («похожи»), хотя истинные периоды 1/720 и 1/2160 с. Различающее наблюдение — когерентная амплитуда на 720: 0,015 против 0 в точной модели. В реальном опыте для обнаружения потребовались бы независимые часы, подтверждённый диапазон пропускания, шумовой предел ниже слабой линии и контроль, связывающий свет с Lenovo. Неразрешённая слабая линия не есть нулевой сигнал.

Устройство не моделировали как реальную линейную камеру с этими параметрами; нет оснований приписывать её строкам синтетические часы, а панели — 720 или 2160 Гц. Следующий офлайн-тест R085: отдельно проверить статичную сцену с refresh-синхронной развёрткой против модели временного общего сигнала.

**Воспроизведение** (в этом каталоге, Python 3, стандартная библиотека): `python3 -B models.py | cmp - results.json`; `python3 -B -m unittest -v`; `python3 -OB -m unittest -v`. [Модели](models.py), [числа](results.json), [проверки](test_models.py): независимый численный DFT прямых импульсов, интегрирование света по экспозиции, смена частоты строк/фазы, отдельный контроль малой линии.
