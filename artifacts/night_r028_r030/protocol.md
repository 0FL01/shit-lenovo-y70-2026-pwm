# R028–R030: протокол архивного переанализа

База d4c56fb, R12b уже раскрыт. Решения ниже записаны до вычисления этих метрик; это не новая слепая проверка. Только файлы. Исходные PNG приватные, идентифицируются публичным операторским manifest; без подмены имен и без отбраковки неудобных кадров.

* R028: берём первый снимок двух разнесённых предъявлений одного и того же C (`p02_1`, `p06_1`, из ключа), без выбора по качеству. По отношению к первому снимку ищем целый сдвиг ±6 preview px через максимум ZNCC среднего RGB в двух прежних неподвижных окнах верхней границы и в четырёх непересекающихся внутренних окнах рисунка (разбить [922,1100,994,1164) пополам по x и y). При точном равенстве сортируем (NCC,dx,dy) по убыванию. Сдвиг окна считаем разрешённым, только если NCC≥0,90, максимум не на границе поиска и превосходит лучший пик дальше 1 px по Чебышёву минимум на 0,01. Для гипотезы общей трансляции нужны все шесть разрешённых окон и размах по каждой оси ≤2 px. Показываем остатки относительно каждого свидетеля, не скрывая неоднозначные окна. Так можно проверить согласованность локального движения в плоскости PNG, но не причину движения камеры и не полную проективную регистрацию.
* R029: искусственный 1D синус, периоды 2,3,4,6,8,12,16 исходных px; четыре начальные фазы (четверти оборота), все k смещений начала crop, ширина 192, интегрирование box k=1,2,3,4 и децимация с шагом k. Границы не дополняем. Принятие периода на данном масштабе требует строгой границы Найквиста P>2k, правильного ненулевого доминирующего бина DFT, и диапазона не меньше 30% идеальных 2 единиц во всех фазах/crop. Иначе unresolved даже при видимом алиасе; это модель, не действительный фильтр UI.
* R030: для 18 слотов воспроизводим R12b bilinear RGB в центрах клеток. Раздельно R/G/B в каждом ряду: median четырёх high минус median четырёх low по раскрытой маске (с учётом знака); итог медиана восьми разностей. Для U произвольный фиксированный контраст по C как sham, не классы источника. Общая положительная ассоциация для этого корпуса лишь если в канале все 15 кодовых оценок превосходят максимальный модуль трёх sham; каждый кадр сохраняем даже если исходный gate отказал. Не оценка оптической модуляции, цветоразличения или SNR.
