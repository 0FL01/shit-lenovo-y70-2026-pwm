# Extra Dim, раунд 2: обратимый контраст на JPEG экрана осциллографа

**Что установлено.** В одном OFF → ON → RETURN триплете (по три still-фото на состояние) нижняя полоса следа заметно менее заполнена в ON. При возврате она снова плотная, хотя отдельные OFF и RETURN фото различаются. Это **изменение изображения на фотографиях** при включении штатной функции на данном стенде. Данные не измеряют частоту, скважность, глубину модуляции, степень улучшения мерцания или комфорт.

**Что зафиксировали.** По девяти исходным EXIF: 4080×3072, ориентация 1, выдержка 59.99832 мс, ISO 5586, f/1.87, эквивалент не использовался: фактическое фокусное 5.56 мм; компенсация экспозиции 0, автоматический WB, вспышка не срабатывала. В 18 пригодных **PREVIEW**-снимках метаданных до и после каждого shutter: AE LOCKED, AF FOCUSED_LOCKED, focusDistance 6.75919294, 2×, те же ISO и выдержка, OIS ON, AWB AUTO с awbLock OFF. Первое post-чтение OFF2 содержало только frameCount: оно отклонено, повтор дал полноценную запись. 9/9 JPEG декодированы и пригодны для указанной растровой метрики; нет 9 точных Camera2 STILL capture results с привязкой ко времени сенсора. Дата JPEG в EXIF не согласована с датой хоста; не выравнивали серии по EXIF wall-clock. Приватный host log задаёт порядок. В отдельном журнале цели одинаковый хеш центрального прямоугольника Android-скриншота во всех трёх фазах (не оптический уровень); цветовой трансформ Extra Dim меняет выход после этой проверки.

**Регистрация.** Для исходных фотографий один crop (1120,620,2920,2930), поворот по часовой стрелке на 90°, LANCZOS до 550×429. За базу взят OFF1. По контрольному фрагменту сетки y=65:125, x=183:250 максимум Pearson NCC в поиске ±3 px был при нулевом сдвиге на всех девяти фото, r≥.98919. Максимумы градиента левой/правой границы на 37/527 px во всех кадрах, верхней — 44 или 45 px. Никакого компенсирующего смещения к следу не применялось. Субпиксельный дрейф или изменение резкости не исключены.

| Состояние | Фото | Заполнение R>192 в нижней полосе | Заполнение по относительному порогу |
|---|---:|---:|---:|
| OFF | 3 | 59.9–70.0% | 60.5–70.5% |
| ON | 3 | 9.0–10.0% | 8.6–9.5% |
| RETURN | 3 | 53.4–62.9% | 53.2–64.0% |

Доля относится к **пикселям изображения**, не к интенсивности/скважности света. Для вторичной проверки, в той же нижней полосе y=276:322, x=51:508, определён индивидуальный порог R как порядковый 96-й перцентиль контрольного участка сетки y=60:135, x=180:256. Получено 188…199. В каждом столбце считали долю пикселей выше порога. D = среднее абсолютное расстояние между отсортированными наборами этих долей (Wasserstein-1; диапазон 0…1). D не зависит от перестановки столбцов, поэтому нет подгонки фазы, но теряется временной порядок. Это другая геометрия/маска, не переносить числа D на старые серии с PNG. Пороги и анализ чувствительности описательные, не независимое подтверждение другим прибором.

| Пара фаз | Медиана D | Минимум…максимум |
|---|---:|---:|
| OFF → ON | .526 | .510… .620 |
| ON → RETURN | .449 | .437… .554 |
| OFF → RETURN | .072 | .028… .173 |

Внутри каждой тройки D≤.108. Все 18 межфазных пар с ON отличаются сильнее, чем все 18 контрольных пар (внутри каждой фазы и между двумя OFF), при первичной настройке. Разделение сохраняется при порогах R=.94/.98, сдвигах анализа на ±3 px по x или y и в зелёном канале. **В синем канале** интервалы отдельных пар перекрываются (межфазный минимум .157 < контрольного максимума .177); не расширять вывод на произвольный цветовой тракт. Три снимка на фазу одного последовательного прохода не независимые повторения OFF/ON/RETURN. Ни p-value, ни проверка эквивалентности не заявляются.

**Предел доказательства.** AE/AF lock и EXIF стабилизируют часть параметров камеры, но не AWB, локальный тонмаппинг, JPEG/шумоподавление, OIS, фазу экспонирования относительно развёртки, тип считывания затвора, persistence и trigger осциллографа. Длинная выдержка при съёмке **экрана прибора** может наложить несколько обновлений; это не 60-мс интегратор напрямую на OLED телефона. Доля пикселей R=255 в нижней полосе достигает 19.95% (минимум серии 1.36%): насыщение JPEG делает преобразование амплитуды ненадёжным. Даже при идеально стабильной геометрии происхождение изменений фото не разделено на оптику, электрическую наводку и особенности формирования изображения; AC-тракт не даёт DC-составляющую. Не преобразовывать пороги/число переходов в герцы или процент оптической модуляции.

**Воспроизведение.** Из этого каталога с numpy/Pillow из корневого requirements запустить `python analyze.py /path/to/trusted/retry NEW_DIR`, затем сравнить [frames.csv](derived/frames.csv) и [pairs.csv](derived/pairs.csv). Кадры и сырые журналы не публикуются. `python -m unittest discover -s . -p test_analyze.py` проверяет известный сдвиг сетки, насыщенный reference, фазовую/монотонную инвариантность и крайние D. Скрипт предназначен только для этих именованных кадров и проверяет заявленный EXIF/соседние PREVIEW, не аутентифицирует происхождение файлов.
