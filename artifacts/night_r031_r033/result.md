# R031–R033: изменение готового растра не является общим множителем; шкалы R7 совпали

Три архивные задачи A, ни одной новой съёмки. База d4c56fb; [правила до вычислений](protocol.md), [покадровые результаты](outcome.json). В физических сериях участвовали отдельная камера Nothing A001 и Lenovo XT2611-1 GLOBAL. В этом аудите устройства не опрашивали, возврат не требовался.

## R031 / DONE: прямой код и фон изменились даже в разные стороны

Одна серия [R11](../stock_expert_direct_r11_20261118/result.md), один неподвижный известный A и один объектив Expert 0,6×. Из пяти запланированных архивных изображений все пять найдены и разобраны; исключено ноль. Каждая строка — две области *одного и того же* PNG, 1280 точек на область: одинаковая форма, сдвиг −800 px для фона. Y′ — взвешенный средний готовых 8-битных RGB, не световой поток.

| PNG | Средний Y′ кода | Средний Y′ фона | Точки с любым каналом 255: код / фон |
|---|---:|---:|---:|
| expert_wide, AUTO | 221,34 | 4,48 | 645 / 0 |
| short_drag | 47,86 | 8,76 | 0 / 0 |
| short2 (прежний отказ по коду) | 44,33 | 9,12 | 0 / 0 |
| short3 | 50,25 | 9,57 | 0 / 0 |
| short4 | 49,75 | 9,84 | 0 / 0 |

Для AUTO/короткого отношение яркостей прямой зоны 4,40–4,99, фоновой 0,456–0,512. Отношение этих отношений 9,04–10,15 вместо единицы: **0/4** в заранее заданном интервале ±множитель 1,10. Ни одного нулевого канала в этих центральных выборках. В AUTO более половины точек прямой зоны имеют канал 255. Пары зависят от одного AUTO и не являются четырьмя отдельными опытами.

**confirmed-other-device:** единый мультипликативный пересчёт готовых средних не описывает этот архив, даже по знаку изменения. **unknown:** причинный эффект gain при фиксированной выдержке. Здесь не меняли изолированно ISO: по журналу ISO 6400 в обоих режимах, latest выдержка менялась 60,008 мс AUTO → 156 мкс, AE/обработка не эквивалентны; нет связи screenshot с одним sensor frame. Уровни близ тени, клиппинг и обработанный preview исключают интерпретацию чисел как отношения оптической амплитуды. Различающий тест: парные несклиппированные линейные данные, измеренный чёрный уровень, фиксированные свет/выдержка и независимое варьирование усиления.

## R032 / DONE: консервативная карта, не разрешение на перенос

[Полноразмерная индексная карта](roi_map.png), 1080×2392, начало слева сверху. Это нарисованные классы без исходных пикселей; каждый индекс — разрешение на **конкретную** роль. Индекс 1/оранжевый — 1280 центров прямого кода в [914,1011)×[1085,1182); индекс 2/голубой — только фоновый контроль в [114,211)×[1085,1182), тоже 1280. Внутри ограничивающих прямоугольников действительны только помеченные точки, а не всё поле. Ближайшая точка прямой выборки отстоит от правого края на 69 px (1079−1010); это не запас до края физической панели. Индекс 3/фиолетовый — только координаты двух исходных [свидетелей локальной геометрии](../stock_blind_static_r12_20261118/geometry/README.md), не код/фон.

Индекс 0/тёмный — всё прочее **запрещено для сигнала**, включая интерфейс, зону прибора (весь центральный коридор 280≤x<900 исключён), края и промежутки между окнами. Нельзя заменять фон бликом/подписью, измерять прочие пиксели ограничивающего прямоугольника или трактовать фон как подтверждённую матовую мишень. Ошибочная компоновка, поворот или иные размеры — отклонить карту, не тянуть её по новому экрану. На *новом* наборе проверять фактический режим, исходный witness и headroom на всех 2944 соседях, плюс отдельно endpoints обеих центральных выборок; сохранять предупреждения о нуле, не выкидывать отдельные пиксели или прежние отказы. При отсечке не считать зону пригодной для сравнения яркостей. По пяти из пяти проверенных R11-кадров количество и непересечение точек подтверждены, AUTO обнаруживает описанный клиппинг; новых проверенных наборов **0**. Карта — подтверждённая геометрия программной маски, пригодность в новой съёмке и полный projective transform — **unknown**.

## R033 / DONE: отдельная визуальная запись легенд для каждого реально существующего слота R7

Источник: [R7, ручной Open Camera 1×, 500 мкс, ISO 6400](../stock_dbv_association_r7_20261118/result.md); это *иной* ракурс, не карта R032. По трём отдельным кропам нижних плашек каждого фазового PNG прочитаны **X1 / 5mS / AC во всех 43 из 43 доступных**. Читаемая надпись 5mS — показание горизонтальной шкалы 5 мс/дел, не проверенная длительность деления. Ручная разметка привязана к исходным PNG в [51-строчном манифесте](legend_reads.csv). 51 плановый слот, 42 ранее принятых; P14_s0 прочитан, но **остаётся отклонённым** по исходной проверке букв; остальных 8 PNG нет. Квалификация/стартовые референсы вне фазового знаменателя. Этот аудит не выдаёт сходство шаблона за OCR; воспроизводимая часть сверяет идентичность файлов и изолирует группы различных/нечитаемых шкал, но не подменяет чтение человеком или моделью.

**confirmed-other-device:** на рассмотренных R7-фазах визуальных конфликтов трёх подписей нет, отсутствующим слотам ничего не присвоено. Упомянутые [раньше](../scope_calibration_20261118/result.md) кадры с 1 мс/дел не включены в группу R7 с 5 мс/дел и здесь не проверялись. Физический множитель щупа, поверка развёртки, источник сигнала и ШИМ — **unknown**. Различающая проверка требует независимого сигнала с проверенным периодом, а не ещё одной фотографии тех же подписей.
