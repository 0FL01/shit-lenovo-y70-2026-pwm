# R049–R051. Проверка пределов цифровых кодов в архивных превью

**Итог:** R051 **DONE** для архивных окон: в 24/24 исходных превью ни в одном пикселе C или R нет канала на 0 либо 255. R049 и R050 **HOLD**: нет независимо обозначенного блика объектива и нет двух сопоставимых независимых серий для оценки знака и разброса. Отсутствие отсечки в этих PNG не превращает окно в фотометр.

**Вопрос и критерий.** Различимы ли изменения кандидата C и отдельного блика; воспроизводится ли знак для одного и того же A/B; достигают ли выходные коды границ? До пересчёта заимствованы окна и цифровой veto из [протокола R044](../night_r043_r045/protocol.md). В растре 1080×2392 C=[370,690)×[310,530), R=[760,990)×[310,530); R — только кандидат в соседний контроль, не маска блика. Любой канал RGB равен 0: пол; любой равен 255: потолок; объединение событий без двойного счёта. Если ≥1% пикселей объединения **хотя бы в одном слоте** любой из двух ROI, правило запрещает атрибуцию. Ретроспектива, не предрегистрация исходных серий.

**Источники и охват.** База 6c72ae3; [штатный белый/чёрный/белый](../scope_color_divergence_20261118/result.md) и [перераспределение равной площади, полный v2](../scope_spatial_stock_20261118/result.md), Nothing PHOTO; Lenovo 120 Гц обновления, DBV 3600, DC OFF по архивным отчётам. Повторно прочитаны 9/9 и 15/15 оригинальных PNG из этих завершённых серий, по три разных слота на фазу. Прерванная пространственная v1 не считается повтором и не включалась. Проверены имена всех слотов, геометрия и воспроизведение min/median/max каждого фазового ln(C/R) до 8 знаков относительно [агрегатов R8](../r8_raster_context_20261118/results.json). Никаких новых съёмок, воздействий или проверок возврата.

**R051 — confirmed-other-device** по архиву Nothing: доля пола, потолка и их объединения равна 0% в каждой ROI, каждом слоте каждой фазы, не только в среднем. В одном слоте C содержит 70 400 пикселей, R — 50 600; суммарно 2 904 000 пиксельных наблюдений, **не** независимых измерений. Это только отсутствие двух крайних выходных кодов; фотообработка, шумоподавление, сжатие теней, чёрная точка до ISP и нелинейность остаются неизвестны. Можно описывать видимость и кодовые разности, не отношение световых потоков или физическую модуляцию.

**R049 — HOLD.** Медианы ln(C/R) для пространственной серии по порядку: 0,22435 → 0,18992 → 0,22827 → 0,19550 → 0,22699. Это ход **двух фиксированных окон кадра**, не результат сравнения с бликом: ни в описаниях этих съёмок, ни в [схеме допуска](../night_r043_r045/protocol.md) нет закреплённой маски оптического блика. Яркий пик в C или его синхронность с меткой не устанавливают происхождение. Не выбирали «наиболее коррелирующий» участок постфактум. Для сравнения нужен независимо размеченный блик той же геометрии; даже тогда это помеха общей оптики, не независимый датчик.

**R050 — HOLD.** У W/B/W средняя фаза меняет суммарный код экрана, в пространственном A/B/A/B/A меняется положение светлых полос. Это разные воздействия без заранее установленного общего направления; не две реализации одного контраста. Как показал [R046](../night_r046_r048/result.md), внутреннее BAB пространственного архива делит кадры с соседними ABA. Пригодных независимых пар для целевого эффекта — 0. Межсерийные знак и разброс **не оценены** (не нулевые); среднее по сериям не вычислялось. Нужны две полные раздельные серии одного контраста с квалифицированной геометрией и контролем. Идентификация рассеивателя по-прежнему заблокирована, физический PWM — **unknown**.

**Воспроизведение:** из этого каталога с NumPy и Pillow передать исходные каталоги WBW и завершённой spatial v2 соответственно. `python -B audit.py "$WBW" "$SPATIAL" | cmp - outcome.json`; повторить с `-OB`; `python -B -m unittest -v test_audit`. В [JSON](outcome.json) сохранены компактные числители и знаменатели по слотам, объединение и флаги порога, без изображений.
