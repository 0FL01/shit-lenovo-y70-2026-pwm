### R055. Когда видимый код восстанавливает масштаб?

В модель поданы 174 пикселя периодического трёхуровневого источника. Экспозиция усредняет уровни прямоугольным окном, в том числе при переходе через начало периода; нулевая экспозиция означает точечную выборку. Алгоритм знает циклическую последовательность A и положительное направление, **не знает** фазу, ширину экспозиции и масштаб. Он ищет соответствие растущих пересечений уровня 1,5 и оценивает наклон прямой по всем фронтам. Отсутствие решения не превращается в нулевую шкалу.

В ячейке: число принятых / максимальная абсолютная относительная ошибка **слотов на пиксель**, %. В каждой ячейке ровно 96 фаз; «0 / —» означает отсутствие оценки. Всего 1920 из 1920 обработаны, 0 исключены.

| px/слот | точка | 0,5 слота | 1 слот | 2 слота | 12 слотов |
|---:|---:|---:|---:|---:|---:|
| 0,75 | 0 / — | 0 / — | 0 / — | 0 / — | 0 / — |
| 1,25 | 96 / 0,01837 | 96 / 0,02920 | 87 / 0,02920 | 0 / — | 0 / — |
| 2,3 | 96 / 0,07934 | 96 / 0,10065 | 96 / 0,13948 | 0 / — | 0 / — |
| 4,7 | 96 / 0,22159 | 96 / 0,32946 | 40 / 0,38948 | 0 / — | 0 / — |

799 оценок, 0 превышений заданного порога 5%; **1121 отказ** (593 недостаточно фронтов, 528 рисунок фронтов не согласуется с допуском). При экспозиции целого цикла сигнал константен по построению. При одном слоте исход может зависеть от стартовой фазы. Более крупный рисунок не гарантирует лучшую оценку на полосе фиксированной длины: в неё помещается меньше циклов. Это оценка фиксированного алгоритма, а не предел разрешения любого декодера.

Проверено только численно для явной модели без шума, при известных уровнях и знаке. **unknown:** ошибка в физической сцене. 0,38948% не доверительный интервал и не погрешность камеры. Не показана устойчивость к мёртвой зоне, нелинейности, взаимной фазе обновления экрана и камеры или реальному jitter. Следующий различающий тест: проверять замороженный масштаб и знак на **другом** коде и измеренных независимых фронтах, не подбирать параметры по этому коду.

### R056. Идентичные уровни, разное модельное время

[Таблица R12](../stock_gc08a8_timing_r12_20261118/result.md) даёт номинальные 13 мкс/строку, а также высоты 2448 и 1836 (центрированный crop, начало 306). **hypothesis** для иллюстрации, не реконструкция кадра: после поворота каждая из двух высот проецируется на одинаковые 153 UI-позиции; положение берём в центре пикселя. Это произвольная модель масштаба, не размеры реального UI. Обе модели имеют одинаковую экспозицию 156 мкс. Слот A занимает три UI-пикселя:

| Модель | Строк на пиксель | Модельные мкс/пиксель | Длительность физического слота, заданная симулятору |
|---|---:|---:|---:|
| Полная высота | 16 | 208 | 624 мкс |
| Crop | 12 | 156 | 468 мкс |

Фаза независимого источника относительно начала считывания неизвестна; в примере начало A совпало с началом выбранного окна в каждом мире. При интегрировании все **153/153** значений идентичны точно, присутствуют все три уровня (0,1,2). Это не два наблюдения одного известного генератора: намеренно варьируется его **неизмеренная** физическая длительность слота. Шкалы отличаются в 4/3 раза, а пиксели их не различают. Вывод — неидентифицируемость по одному рисунку без опоры, а не равная правдоподобность двух трактов либо доказательство crop. Геометрию реального режима ограничивает также [R024](../night_r022_r024/result.md). Различающий тест: независимая запись фактических оптических интервалов с наблюдаемой протяжённой областью, либо подтверждённая привязка sensor buffer → UI и проверка модельного времени.

### R057. Почему нет физического результата

По инвентарю и допуску R052/R053 нет пары «стабильно идентифицированная рассеянная область с кодом в прежней сцене» + «независимая запись его фактических оптических фронтов». Поэтому **HOLD, 0 начато / 0 снято / 0 принято**, физическая шкала **unknown**. Запрос кадров, временные метки Android, фотографии шкалы прибора и синтетика не заменяют эту пару. Сцену не трогали, возврат не требовался. Возобновлять лишь при наличии самой пары, не переносить R055 на стенд.

`python3 -B audit.py | cmp - results.json`, `python3 -B -m unittest -v`, `python3 -OB -m unittest -v`. Семь проверок в каждом режиме; сравнение результатов побайтно.
