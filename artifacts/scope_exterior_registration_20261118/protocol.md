# Замороженный план: яркие экранные легенды прибора, вне графика

Новый **диагностический** критерий для будущих неизменных камер/положения/развёртки, не способ пересмотреть отказы старого опыта. Код и этот план фиксируются до первой оценки остальных исходных PNG. Разработка: только new_qual0 первой граничной серии, один кадр. Тест: *все* оставшиеся new_qual*, P??_s? и R?? из трёх последовательных сессий (две целые сессии не использованы при выборе), без подбора новой фотографии. Их действительное механическое смещение неизвестно; это отложенная оценка согласия, не истинная разметка.

Четыре ярких объекта — метка AUTO вверху слева и три нижние плашки вертикальной шкалы, развёртки и RUN. Выбор определён устройством интерфейса прибора, не волной. Остальная часть изображения, включая белый ползунок камеры, не используется даже при поиске. В фиксированном RGB выбирается max(R,G,B); поиск ±6 px по нормированной корреляции (NCC) с исходным шаблоном, координата пика уточняется параболой отдельно по осям. Оценка в пикселях предпросмотра, не калибровка единиц осциллографа.

Все четыре объекта обязательны. Другая камера/масштаб, заглушенный или изменённый индикатор, непригодный исходный шаблон — ошибка, а не разрешение переобучить шаблон. Тот же предел смещения 2 px, а не расширенный поиск как допуск. Отдельные барьеры: NCC ≥0.92; P90−P10 ≥48 кодов (19% полного диапазона), 0.65–1.50 исходного; 95-й процентиль градиента по обеим осям, нормированного на контраст, не ниже 65% шаблона; максимум каждого канала <250; устойчивая мера остатка ≤1/8 контраста. Шаблон тоже имеет минимум нормированного градиента 0.10. Это инженерные запасы для ярких объектов, не статистические доверительные интервалы. Нули на чёрном фоне не удаляются; геометрию узнаём по светотёмным переходам, но отсюда нельзя выводить линейность канала.

Синтетика: на нескольких базовых кадрах — сдвиги ±1 и ±4 пикселя по обеим осям, дробный сдвиг для оценки погрешности, размытие Pillow radius=3, обесцвечивание контраста до 0.25, локальное закрытие одной метки, насыщение, изменение содержимого всей области графика при неизменных легендах. Публиковать все результаты, не корректировать критерий после вскрытия. Ограничения: верхний правый угол не имеет яркой независимой надписи; опоры не охватывают весь прямоугольник. Локальное искривление/дефокус в центре и движение прибора относительно фотодатчика не исключаются. Настройки прибора, камеры и динамический диапазон **следа** проверяются отдельно; геометрия не означает, что PWM измерен. Для применения требуется свежий фиксированный sham без смены старых решений задним числом.
