# Повторяемость видимого следа при одном DBV = 2632 (51 скриншот, 17 троек)

**confirmed-on-target:** в [исходной sham-серии](../stock_dbv_2632_badge_sham_20261118/result.md) нативный управляющий код оставался 2632 по проверкам границ троек; это не отсчёт фотодиода. **confirmed-other-device:** даже при совпадении всех четырёх внешних плашек на каждом из 51 Nothing-превью видимый след не идентичен. **unknown:** связаны ли различия с самой панелью, оптическим трактом/триггером прибора или пересъёмкой. Манипуляции с устройствами для этого анализа не выполнялись. Нет физической частоты, глубины модуляции, отсутствия низкочастотной огибающей или испытания переносимости.

## Наблюдение

Взяты все S00…S50 по порядку, без трёх предварительных эталонов R и без подбора кадров. Семь вариантов [ранее зафиксированного анализа](../stock_dbv_2632_20261118/analysis_ordinals.md) применены без изменений. D — среднее абсолютное различие двух **отсортированных** векторов из 428 долей жёлтой маски по высоте фиксированной полосы. Оно не зависит от перестановки столбцов и не определяет период. Для пары разных троек Dmed — медиана 9 попарных D; внутри тройки — медиана 3. Числа ниже безразмерны, min / median / max по **парам блоков**.

| Сравнение при неизменном коде | Пар блоков | Первичный Dmed |
|---|---:|---|
| Внутри тройки | 17 | 0.010099 / 0.012383 / 0.020742 |
| Соседние тройки | 16 | 0.010021 / 0.012474 / 0.014875 |
| Интервал ≥8 троек (разведочный разрез) | 45 | 0.009943 / 0.012409 / 0.020171 |
| Все пары разных троек | 136 | 0.009216 / 0.012760 / 0.020171 |

Интервал ≥8 означает **разность номеров** блоков ≥8. Удаление во времени здесь не сопровождалось заметным ростом медианы D относительно соседей, но разброс велик. Медианная площадь маски по тройкам: 57.52% в первой, 56.24% в последней; промежуточные 55.90–57.41%, без простого монотонного тренда. Это единичная реализация, не разделение шума и дрейфа на компоненты. Нулевая отсечка синего присутствует в 39.88–42.40% пикселей широкой контрольной области x112:540, y1080:1270; это не доля нулей в узкой полосе D. Почти неизменные координаты узкого максимума средней линии (1126–1127 px, единственный максимум в 47/51 кадрах) не гарантируют совмещения графика.

Между началом первого и последнего получения PNG **446.751 с**; интервалы между стартами 5.076 / 9.140 / 12.877 с, между первым и третьим в тройке 14.229 / 14.858 / 15.516 с. Команда получения одного PNG занимает 1.972 / 2.155 / 2.195 с; это не длительность экспозиции камеры (задано 500 мкс), не запись двух секунд сигнала и не длительность одного осциллографического развёртывания. На выходе один preview на слот, несинхронный со сменой растра осциллографа.

В каждом из 51 кадров в узкой жёлтой полосе есть локальные максимумы корреляции на лагах 11, 23, 34, 57, 68, 91, 125 **пикселей** (фиксированный поиск лагов, r>0.25); в отдельной синей полосе ни одного прошедшего максимума. Нельзя исключить растровый/фазовый артефакт из-за отсутствия пика у другой цветовой маски; также нет доказательства нестабильности генератора. Никакого превращения этого наблюдения в герцы.

## Проверка старого порядка как отрицательного контроля

Ретроспективно наложили на те же 17 одинаково заданных троек исходный [порядок 17 фаз](../stock_dbv_2632_20261118/result.md), только как фиктивные метки. Учитывались соседние переходы в обоих направлениях, одношаговые соседние контроли по обе стороны, все одинаковые метки (в т.ч. повторы), все внутриблочные пары; дальние между разными метками не объявляли переходами. Минимум Dmed шести фиктивных пересечений = 0.010410; максимум 63 контрольных Dmed = 0.020742. Запас = **−0.010332**, ложного разделения на этом прогоне нет. Для порога 12/24 и сдвигов x/y ±3 тоже нет (запасы −0.020145…−0.008671). Правило требует строго положительного запаса. Реальные команды на смену/повтор яркости, возможные переходные процессы, временные интервалы полноценной A/B-процедуры, ответ на 2633 и отдельный положительный контроль **не имитировались**. Это не проверка на реальном эффекте и не доверительный интервал/минимально различимый эффект.

**Дизайн:** показано, что один заранее заданный порядок не дал ложной границы в одной стационарной серии. Нельзя вычислить специфичность/мощность из этих пересекающихся пар; фиксированный порядок может спутать плавание прибора/камеры с фазой. Одновременное сравнение с соседями, возвраты и одинаковые коды существенно информативнее одной пары A/B, но даже воспроизводимое различие D говорит о растре, не о физической частоте. Для отдельного будущего теста: до данных фиксировать независимые серии со сбалансированными случайными направлениями, холостыми командами и соседями, одинаковой выдержкой после команды, измерением readback на границах и отдельным положительным контролем; не калибровать отсечку на этой же выборке и не выдавать 51 кадр за 51 независимый эксперимент. Для заявлений о самом источнике добавить независимые отсчёты прибора с проверенной временной базой, частотой дискретизации/полосой и оптической связью; для глубины — DC и тёмный отсчёт. Частотную чувствительность распределения площадей D отдельно не предполагать.

## Воспроизведение

Нужны Python 3, NumPy, Pillow и разрешённый приватный каталог S00…S50.png + sham_validity_series.json. Из этого каталога артефакта:

    python3 analyze.py PRIVATE_INPUT NEW_OUTPUT
    python3 check_primary.py PRIVATE_INPUT NEW_OUTPUT/ordinal_pairs.csv

Скрипт проверяет индексы, внешние допуски и временную последовательность. Раскладка в псевдо-P00…P16 создаётся только во временной директории; затем запускается оригинальный analysis_ordinals.py. Публичные результаты содержат лишь порядковые индексы/производные признаки: [кадры](results/ordinal_frames.csv), [пары](results/ordinal_pairs.csv), [сводка](results/summary.json). Второй скрипт независимо считает целочисленную маску и подтверждает min/median/max для всех 153 первичных строк с точностью сохранённых CSV. Приватные снимки, пути, журналы и идентификаторы в артефакт не включены.
