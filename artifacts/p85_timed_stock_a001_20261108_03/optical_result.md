утверждать безусловное «оптика не изменилась», выдавать p85-stock-review-v1
или разрешение candidate14.

## Числа и ограничения

Поиск fine 0,015–0,025 выбран по baseline до сравнений. Найденный q
зафиксирован. Основной расчёт: spatial quadratic detrend + Hann,
без вычитания временного среднего.

| ROI | sham / baseline fixed fine | return / baseline fixed fine |
|---|---:|---:|
| left | 1,0096707545 | 0,9941950349 |
| main | 1,0108993932 | 0,9917413496 |
| right | 1,0073417661 | 0,9953594703 |

Main mean Y: 31,76423071 → 31,89954630 → 31,78089738.
Main normalized fine: 0,2829592272 → 0,2860433111 → 0,2806223659.
Все ROI: Y=14–46, без Y≥235. Fine вывод сохраняется для detrend
None/1/2/3; fixed 2q/3q близки к baseline.

RMS/(mean Y−16) — метрика кодов камеры, не физическая глубина модуляции.
Полный диапазон 0–0,5 цикла на строку, total/coherent/incoherent,
detrend sensitivity и блоки сохранены в [JSON](optical_analysis.json)
и [NPZ](optical_profiles.npz).

Почему результат ограничен:

- Full-spectrum relative L2 amplitude difference sham: 14,03–15,41%;
  return: 5,39–5,50%. Это расстояние кодовых амплитудных кривых,
  не процент оптической мощности.
- Наибольшая sham-разница около q=0,00500 в широкой структуре;
  return-разница около q=0,01709, на плече fine-пика.
- Main q/6: 0,07187507 → 0,08011510 → 0,07154771.
  Sham/baseline left/main/right: 1,05174 / 1,11464 / 1,02897;
  return/baseline: 0,99324 / 0,99545 / 1,06245.
- Main sham q/6 при None/1/2/3 detrend:
  0,70965 / 0,82088 / 1,11464 / 1,00500. Направление оценки меняется.
  Return: 0,93080 / 0,91050 / 0,99545 / 0,96756.
- Main 20-кадровые q/6 блоки: baseline 0,06824–0,07840;
  sham 0,07483–0,08837; return 0,06713–0,07643.
- Main tail maximum 0,1–0,5:
  0,05760317 → 0,05175880 → 0,05505754.

В ROI менее двух периодов условного q/6; q/6 не объявляется физическим
fundamental. Соседние ROI/короткие блоки не являются независимыми опытами.
Экспозиция, ISP, нелинейность и aliasing ограничивают вывод. Эти три
stock-only повтора не отделяют вклад камеры/фазового сэмплирования от
изменения света в широких компонентах. Полный waveform, низкочастотная
огибающая, ≥2000 Гц и комфорт не установлены.
