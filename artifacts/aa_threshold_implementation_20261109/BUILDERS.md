# AA fixed builders and fault tests (offline only)

Implemented `06-tools/aa_threshold_trial.py`, `06-tools/test_aa_threshold_trial.py` and one allowlist addition (`aa10`) in `dsi_trial_transaction.transaction_script`. No hardware, host deployment, Git commit or push occurred. Runtime integration is a separate owned task; these builders are not admission.

- `fixed_programs()` uses source-bound875-byte OFF data, verifies pinned stock and AA10 SHA256, and changes only zero-based offset77. `programs(root)` additionally verifies the saved nativeON and OFF transport-state provenance offline. Runtime does not silently depend on missing artifact files.
- `writer_script` only accepts exact stock/AA10 programs; chunks root600 under root700 directories are hash/length checked before native dispatch. The shared five-chunk transaction remains253/247/254/110/11, final75 controller returns. New wrapper also checks immutable event prefixes before every next block. Stock/A9 shared transaction command rendering remains byte-identical against committed HEAD.
- `selector_script` has exactly A9 short1,9D short1,DBV short2. Every page/read operation is followed by native callback/control and prefix validation before the next operation. Read payload is captured immediately after the qualified read, before page0; this precise composition requires its own stock surrogate. No AA read is generated.
- Normal selector return writes page0 and verifies ESD `reg_read`. Failure trap only unmounts. No page0, ESD or stock write is appended after uncertainty. Actual return-code and full host validation remain caller requirements.
- All child scratch files are exclusively created in owned root700 directories, root600/non-symlink. Successful children remove them. Failed children retain them for qualified recovery cleanup, never reuse. Names: transaction_trace,transaction-previous,transaction-events,transaction-prefix,selector-trace,selector-previous,selector-events,selector-prefix.
- Main trace setup/ownership/cleanup, active clocks/watchdogs, current identities/source/originals, one-shot candidate latching, camera holds, all-phase C1, precise runtime accounting and finalizer are deliberately not claimed by this helper slice.

Validation: `PYTHONPATH=06-tools python3 [-O] -m unittest test_aa_threshold_trial test_dsi_trial_transaction -v` passes19 tests in normal and optimized mode. Logs are tests_normal.txt/tests_optimized.txt. Cases cover1750 individual table mutations; exact wire and selector/readback faults; both writer shells under each of five per-block native failures and prefix corruption; predispatch hash/symlink rejection; selector native failure at all10 operations, prefix corruption at9 positions, and a failing prefix reader with empty initial prefix. Simulated native operations affect only ordinary temporary files; generated shell gates really execute.

These results establish offline implementation behavior, not runtime compatibility, DDIC latch restoration, a timing bound or physical PWM frequency. Unknown AA10 has not executed.

Independent review correction: initial event-prefix extraction previously masked grep rc2 when its output was empty. Both generated children now explicitly accept only grep rc1 plus empty output as a no-match case; every other nonzero result is terminal before native dispatch. Executable regression tests inject rc2 against empty and nonempty initial traces, require zero native operations for both writer programs and selector, and retain success on genuinely empty initial traces. This supersedes the earlier18-test freeze.
