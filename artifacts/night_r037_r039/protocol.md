# R037–039: ретроспективный план до пересчёта

База de0ed65, фотографии и прежние выводы известны, для выбора наружной зоны просмотрена миниатюра 1A-1. Это не слепая выборка. Только архив и синтетика; новых состояний/изображений не создаём на стенде.

* R037: у пары прямоугольников шириной 7 отсчётов с периодом шаблона 48 отсчётов сопоставить фактический минимальный период дискретного шаблона с расстоянием одноимённых фронтов штатного scope_pwm.measure. Положения 0/24 либо 0/18, высоты 40 и 40/38/32/20. При равных одинаково разнесённых пиках минимальный период именно 24. Не присваивать фундаментал при одном лишь интервале фронтов; фиксировать, предупреждает ли детектор об отличающихся циклах. Одна детерминированная матрица 2×4, не оптическая калибровка.
* R038: все 30 исходников двух манифестов scope_calibration, сверка SHA-256 по существующей ведомости. Развести группы белый/чёрный HTML (90 Гц), белый ярче, белый при 120, исходное приложение до настоящего OFF, OFF и экран блокировки после пробуждения, исходное приложение после возврата. Не объединять в одно A/B/C. Без перенастройки применить ранее описанные верхнюю/нижнюю полосы и порог q=.97 scope_divergence; доли пикселей над порогом по каждой полосе. Сохранился ли видимый не-плоский рисунок ниже средней линии во всех трёх OFF (нижняя доля выше максимума триплета before и триплета restored)? Доля не есть физическая амплитуда; период OFF не выделять по максимизатору настроенного интервала.
* R039: только финальный spatial v2, 5 фаз A/B/A/B/A по три фото, имена из опубликованной таблицы. Сопоставить на одинаковых парах один старый показатель графика D и новые показатели одного внешнего контроля (исходный растр, x=180:550, y=400:545, тёмный край округлого объекта над прибором, не UI, не дисплей прибора). D — первая компонента scope_divergence.distances. Наружная зона: средний модуль RGB-разности совпадающих пикселей и абсолютная разность средних RGB-кодов (модуль разности средних всех каналов и пикселей). Сообщить долю RGB=0/255, диапазон ненулевого контраста, сдвиг при синтетическом +10% кодов (не эталон чувствительности). На неизменённой геометрии сравнить min 54 межрисуночных с max 51 однорисуночных пар отдельно для каждого признака, а также медианы по фазам. Положительный зазор только на графике отвергает лишь объяснение столь же хорошо разделяющим изменением выбранного внешнего признака, не изменение автоэкспозиции вообще. Один внешний участок не представляет весь видоискатель.
