# R013–R015. Проверка архива R12b после раскрытия

**Три архивных проверки DONE; новых опытов на телефонах — ноль.** Повторная обработка всех 18 исходных PNG дала запечатанный ранее файл ответов и исходный score байт-в-байт. Это проверка воспроизводимости, не повтор физического опыта. Прежний результат не повышен: кодовые кадры со всеми pixel gates 9/15, с геометрическим контролем одновременно 6/15 по отчёту R12b. Никаких измерений частоты или глубины ШИМ.

Проверки этого отчёта выполнены на архивном хосте; устройства не опрашивались и не изменялись, нового возврата не требовалось.

**Воспроизведение.** В каталоге пакета: `python3 -B -m unittest -v test_audit` и `python3 -O -B -m unittest -v test_audit`: по 4 теста прошли, включая пропуск, дубль, нарушение порядка, неподтверждённое завершение, несовпадающие байты и лишнюю правку декодера. На Python 3.13 с NumPy 2.5.0/Pillow 11.1.0: `python3 -B audit.py R12B_DIR --private FROZEN_DIR ORDINAL_PNG_DIR OPERATOR_DIR`; без `--private` только публичные проверки и явный SKIP приватного replay. Для полного replay недостаточно одной папки R12b. Переносимый декодер читает публичный [locked_transform.json из соседнего каталога R10](../stock_direct_image_r10_20261118/analysis/locked_transform.json), то есть `R12B_DIR/../stock_direct_image_r10_20261118/analysis/locked_transform.json`. Его SHA-256 — `952bde8317f3fe1227719dc042bff16ec8e72bd826301ba8ca712b7276b4f631`; копия из geometry/ внутри R12b имеет те же байты, но не подставляется автоматически. Первоначальный замороженный декодер независимо требует свой исторический путь к геометрии; не редактировать его для обхода. Сырые кадры и закрытый ключ не публикуются. Следующий различающий тест — R016: сравнить декодер с постоянным прогнозом и одним заранее фиксированным пространственным шаблоном, не трактуя клетки как независимую выборку.
