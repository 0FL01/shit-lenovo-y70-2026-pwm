# R40: один разрешённый кандидат `02`, не перепись банка данных

**Проход завершён по правилу останова.** На `02:FE` пришёл DCS **long** с `WC=3`, данные `02 00 00`; принятый для этого опыта short1 не получен. Новый ID запрошен **один раз из разрешённых семи**. `02:80`, `02:82`, `02:BA` не запрашивались. Статус `02` как независимой страницы — **unknown**, а не «страницы нет» или «банк обнаружен».

**Объём разрешения.** 21 ноября владелец подтвердил [точное предложение R39](../ddic_r39_known_guard_20261120/result.md#следующий-живой-опыт--только-предложение-не-выполнен): на XT2611-1 при stock DC OFF, DBV 1024, обычных 120 Гц начать с контроля `23`, проверить `02:FE` и только при правильном ответе — до двух чтений каждого `02:80/82/BA`, закончить известным контролем и восстановлением. Только селекторы страниц и чтение, **не более семи** запросов нового ID. Запись данных регистров, изменённая длина при повторе, прочие страницы, flash и постоянное применение не разрешены.

**Правило до измерения:** для `02` максимум в запросе 3, принимается только фактический DCS short1 с согласованными заголовком, ECC, длиной, счётчиком и возвратом контроллера. Неподходящий формат — останов новых чтений, даже если первый напечатанный байт совпадает с ID. `FE=02` само по себе не устанавливает существование отдельного банка. Сигнатуру сравнивать только по двум воспроизводимым тройкам после разных известных байтов-предшественников; совпадение с архивом — возможное зеркало, не повтор каждого архива на этом DBV. Проверка не измеряет частоту или амплитуду света.

### Что измерено на XT2611-1

| Шаг, одна эпоха wake | Фактический результат | Решение |
|---|---|---|
| Известный `23`, до | `FE/80/82/BA = 23/50/00/00`, native `00:52=0400` | Контроль прошёл |
| `02:FE`, MRPS3 | Заголовок `1c 03 00 16`, ECC согласуется; аппаратный и нормализованный счётчики `9/9`. RX вернул 3 байта. Native controller `[0,3,0]`, page TX `[0,0]`, пропусков проб не зафиксировано | Транзакция завершилась, но `not_dcs_short1`; без следующего opcode и без повтора |
| Известный `23`, после | Те же четыре значения и DBV `0400` | Контроль вернулся; последняя передача селектора `00` подтверждена |

`confirmed-on-target`: на обеих границах всех трёх шагов — `HWC 0 / 120.00 Hz / group 0x3`, та же эпоха и независимое чтение ESD `reg_read`. В [квитанции](receipt.json) сохранены три результата и [строгий разбор](framing.py) отслеживаемого кадра. `transport_verified=true` не равен `framing_qualified=true`. Первый байт длинного ответа совпадает с номером селектора, но это не подтверждение чтения short1 и не отличает эхо от содержимого страницы. CRC полезной нагрузки отдельно не захватывался. Не пересчитывать эти данные в Гц и не менять критерий допуска задним числом.

**Возврат.** До подготовки телефон находился в Android `policy=DIM`, ручные 102, sysfs BL 828; обычный активный уровень при той же пользовательской настройке был перечитан как 6692. После опыта первое пробуждение при уже возвращённой политике min/peak `120.0/0` не прошло внутренний guard штатного applier: `not a fresh stock core; stopped without payload`. Фактические значения в сам момент отказа не записаны. До дальнейших действий независимо проверили `reg_read`, затем штатные поля входа **`0e/0e/50`, `C1=000010`** при BL 6692. На временно зафиксированном ordinary 120 штатный applier прошёл свой обычный wake и подтвердил применение. В конце **`running / active: verified`**, BL 6692, ручные 102, min/peak `120.0/0`, `panelDC=0`, начальная `Settings.SubSettings`, исходный системный таймаут сохранён. Обе временные директории, trace instance и trace events удалены и их отсутствие проверено. A001 не переключалась. Восстановление прежнего сессионного профиля отделено от пробы `02`; сама проба не записывала данных регистров. Для проверки восстановления не повторяли ни одного запроса к `02`.

**Граница следующего шага.** Этот проход исчерпан. Сохраняются 19 архивных страниц с различимыми сигнатурами; новой сигнатуры для `02` нет. Сырой ответ можно повторно проверить **офлайн**: из корня worktree `python3 -B artifacts/ddic_r40_page02_20261121/framing.py "$PRIVATE/fe.step/raw" "$(cat "$PRIVATE/nonce")"` возвращает код `1`, `reason=not_dcs_short1`, `value=null`. Для переноса следующего опыта на аппарат нужен другой, заранее обоснованный критерий (например, отличать стабильный не-FE ответ от эха в режиме long3) и отдельный точный объём. Никакого автоматического продолжения этой серии нет.
