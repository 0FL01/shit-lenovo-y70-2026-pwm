# R40: один разрешённый кандидат `02`, не перепись банка данных

**Объём разрешения.** 21 ноября владелец подтвердил [точное предложение R39](../ddic_r39_known_guard_20261120/result.md#следующий-живой-опыт--только-предложение-не-выполнен): на XT2611-1 при stock DC OFF, DBV 1024, обычных 120 Гц начать с контроля `23`, проверить `02:FE` и только при правильном ответе — до двух чтений каждого `02:80/82/BA`, закончить известным контролем и восстановлением. Только селекторы страниц и чтение, **не более семи** запросов нового ID. Запись данных регистров, изменённая длина при повторе, прочие страницы, flash и постоянное применение не разрешены.

**Правило до измерения:** для `02` максимум в запросе 3, принимается только фактический DCS short1 с согласованными заголовком, ECC, длиной, счётчиком и возвратом контроллера. Неподходящий формат — останов новых чтений, даже если первый напечатанный байт совпадает с ID. `FE=02` само по себе не устанавливает существование отдельного банка. Сигнатуру сравнивать только по двум воспроизводимым тройкам после разных известных байтов-предшественников; совпадение с архивом — возможное зеркало, не повтор каждого архива на этом DBV. Проверка не измеряет частоту или амплитуду света.
