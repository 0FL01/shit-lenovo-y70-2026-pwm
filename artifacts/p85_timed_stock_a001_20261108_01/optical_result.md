# P85 timed stock-only 01: оптика завершённого factory15 прогона

## Итог

**Fine-полосы и mean Y проходят ограниченный диагностический допуск 5%.
Полная эквивалентность спектра/широкой компоненты не установлена.**

Основной baseline q=0,019775390625 цикла на строку, период 50,567901 строки.
По трём ROI fixed fine sham/baseline составляет 1,00763–1,01355,
return/baseline — 0,99401–0,99997. Средний Y изменяется менее чем на 0,56%.

При этом полный нормированный амплитудный спектр return отличается от
baseline на 11,98–12,86% по относительному L2 расстоянию. Широкие компоненты
зависят от detrend/ROI/короткого временного окна. Это не безусловный результат
«оптика не изменилась», не p85-stock-review-v1 и не разрешение candidate14.

**C1 в sham15 не измерялся.** Это явно сохранено как not_measured без data;
его значение не подставлено из baseline или return. В baseline и return
C1 действительно измерен как [0,0,96]. P85=[21,0,0] во всех стадиях.
Физические Hz, комфорт и универсальная семантика регистров не определены.

Fine-поиск 0,015–0,025 задан по baseline до сравнения. Один найденный q
фиксирован во всех стадиях. Quadratic spatial detrend/Hann, без удаления
временного среднего:

|---|---:|---:|
| left | 1,0099469165 | 0,9945828498 |
| main | 1,0076336263 | 0,9940139036 |
| right | 1,0135482996 | 0,9999695203 |

Main mean Y: 31,90416744 → 31,89974074 → 31,76983565.
Main normalized fixed fine: 0,2835804859 → 0,2857452333 → 0,2818829457.
Общий диапазон пикселей трёх ROI: Y=14–48, без Y≥235.
Fine сохраняет результат при spatial detrend None/1/2/3; fixed 2q/3q
также близки к baseline. Нормировка RMS/(mean Y−16) относится к коду камеры,
не к физической глубине модуляции.

Полный диапазон 0–0,5 цикла на строку, total/coherent/incoherent,
detrend sensitivity и блоки сохранены в [JSON](optical_analysis.json)
и [NPZ](optical_profiles.npz). Ограничения видны за пределами fixed fine:

- Relative L2 full-spectrum amplitude difference sham: 3,88–4,43%;
  return: 11,98–12,86%. Это расстояние кривых кодовых амплитуд,
  не процент оптической мощности.
- Наибольшая return-разница: около q=0,005005 для main/right и
  q=0,022461 для left; один совпавший fine peak её не описывает.
- Main q/6: 0,07564701 → 0,08085908 → 0,07310250.
  Return/baseline по ROI left/main/right: 1,00194 / 0,96636 / 0,95701.
- Main return q/6 при None/1/2/3 detrend:
  1,46285 / 1,35638 / 0,96636 / 1,01856. Даже направление оценки меняется.
- Main q/2 return/baseline=0,86890. Это также пространственная
  диагностическая компонента, не установленный физический fundamental.
- Main 20-кадровые q/6 блоки: baseline 0,07240–0,07964;
  sham 0,07434–0,08867; return 0,06860–0,07962.
- Main tail maximum 0,1–0,5: 0,05146987 → 0,05241013 → 0,05757452.
  Различие сохранено, а не объявлено отсутствующим.

В ROI помещается менее двух периодов условного q/6. Короткие блоки
и соседние ROI не являются независимыми повторными опытами. Экспозиция,
ISP, нелинейность и aliasing ограничивают интерпретацию. Полного waveform,
низкочастотной огибающей, частоты ≥2000 Гц или комфорта этот результат
не устанавливает.

## Воспроизводимость

Независимая проверка — PASS в указанном ограниченном смысле. Свежий
ffprobe подтвердил все 2305 PTS; отдельный расчёт primary/stronger timing
plans и запасов совпал. Full-native-Y decode кадров 523/1419/2013 с crop
после декодирования точно совпал с center profiles всех трёх ROI.
Независимый monomial least-squares/Fourier для None/1/2/3 воспроизвёл
нормированные метрики с ошибкой ≤2,36×10⁻¹⁶, full FFT power — ≤1,87×10⁻¹⁴.
Return full-spectrum L2 различия и ограниченный вывод отчёта также
проверены отдельно; hardware/lifecycle/cleanup replay прошёл независимо.

Второй полный decode воспроизвёл JSON побайтно и все 32 NPZ-массива точно.
[optical_validation.json](optical_validation.json) сохраняет сравнения,
блоки, более строгие временные запасы и явный middle_c1_status=not_measured.
[validate_optical.py](validate_optical.py) проверяет те же условия повторно.

Исходные run/video, старые результаты и shared sources не изменены.
